# 物理常数与单位换算速查

> 用途：VASP / ALAMODE / 后处理脚本里**单位换算是最高频的出错点**（kBar vs GPa、Bohr vs Å、eV vs Hartree），
> 本页集中备查。来源：天帝君豪博客《常用物理单位与物理常数》
> （`articles/20261001-常用物理单位与物理常数_天帝君豪的个人博客.md`）。
> ⚠️ 原文的晶胞体积公式在网页上被排版破坏（FCC 写成 `a^{3/4}`、BCC 写成 `a^{3/2}`），下表按**正确值**给出并标注。

## 物理常数

| 量 | 值 |
| --- | --- |
| 普朗克常数 `h` | 6.62607015×10⁻³⁴ J·s |
| 约化普朗克常数 `ℏ = h/2π` | 1.054571818×10⁻³⁴ J·s |
| 玻尔兹曼常数 `k_B` | 1.380649×10⁻²³ J/K |
| 阿伏伽德罗常数 | 6.02214179×10²³ /mol |
| 光速 `c` | 299792458 m/s |

## 能量

| 换算 | 值 |
| --- | --- |
| 1 Hartree | = 2 Ry = 27.211396 eV |
| 1 kJ/mol | = 0.0103642688 eV/atom |
| 1 eV | = 1.6021766208×10⁻¹⁹ J |
| `k_B·T`（VASP 里的"电子温度"） | = 8.6173333331×10⁻⁵ × T（eV，T 单位 K） |

## 长度

| 换算 | 值 |
| --- | --- |
| 1 Bohr | = 0.529177208 Å |

## 力

| 换算 | 值 |
| --- | --- |
| 1 Ry/Bohr | = 25.71104309541616 eV/Å |
| 1 Ha/Bohr | = 51.442208619083232 eV/Å |

## 压强

| 换算 | 值 |
| --- | --- |
| 1 eV/Å³ | = 160.21766208 GPa |
| 1 Ha/Bohr³ | = 29421.02648438959 GPa |
| 1 kbar | = 0.1 GPa |
| 1 GPa | = 10 kbar = 145037.738007218 pound/inch² |
| 1 Mbar | = 100 GPa |
| 1 TPa | = 1000 GPa = 10 Mbar |
| 1 Gbar | = 100000 GPa |
| 1 atm | = 1.01325 kbar = 0.000101325 GPa |
| 1 Pa | = 10⁻⁹ GPa |

> **最常用的两处**：VASP 的 `TOTAL ELASTIC` 与应力输出是 **kBar** → `×0.1` 得 GPa（`workflows.md` 第十八节）；
> SNAP 数据集要 **bar** → `×1000`（`workflows.md` 第二十一节）。

## 声子频率

| 换算 | 值 |
| --- | --- |
| 1 THz | = 33.35640952 cm⁻¹ |
| 1 THz | = 4.13566553859598 meV |
| cm⁻¹ → Hz | 乘光速 `c`（`c·f[cm⁻¹] = f[Hz]`） |

## 常见晶胞体积（`a`、`c` 为晶格常数）

| 结构 | 体积 |
| --- | --- |
| 简单立方 SC | `a³` |
| FCC | `a³/4` ← 原文排版成 `a^{3/4}`，**以 `a³/4` 为准** |
| BCC | `a³/2` ← 原文排版成 `a^{3/2}`，**以 `a³/2` 为准** |
| HCP | `(√3/2)·a²·c` |
