1.结构优化

2.计算光学性质，在做静态自洽的INCAR中加入光学相关参数即可，下面是我重复InSe所用到的INCAR

SYSTEM = InSe

ISTART = 0

PREC = Accurate

ENCUT = 500

GGA = PE

NSW = 1

ISIF = 3

ISYM = 2

IBRION = 2

EDIFF = 1E-05

EDIFFG = -1E-2

ALGO = Normal

LREAL = .FALSE.

ISMEAR = 0

SIGMA = 0.02

ICHARG = 2

LPLANE = .TRUE.

LWAVE = .F.

LCHARG = .F.

LOPTICS = TRUE ！开启光学计算

NEDOS = 2000 类似于DOS，控制DOS网格密度

CSHIFT = 0.1 ！复数介电函数虚部的一个参数

NBANDS = 120 ！计算需要很多的空带，考虑更多种跃迁的可能。

其中ALGO其实在官网上介绍是得用Exact这个参数，但是这个参数测试了一下，几乎算不动大家在计算也可以低精度一步一步提高试试

在网上看到许多教程，都是先做scf,接着利用自洽的波函数和电荷密度再加入光学计算参数计算光学性质，用PBE测试发现，其实差别很小，应该是可以直接在SCF加入光学计算参数进行计算的。感兴趣的可以自己测试一下

但是光学性质的计算，对于泛函精度的要求非常高，其实从理论上也不难理解，光子从价带跃迁到导带会带来能量变化，对带隙很敏感。所以一般选用精度更高的HSE杂化泛函。
