### 0 一些概念

- 饱和磁化强度：指磁性材料在外加磁场中被磁化时所能够达到的最大磁化强度叫做饱和磁化强度。也就是在外磁场作用下自旋方向趋于一致。

- 磁各向异性能：饱和磁化强度矢量在铁磁体中取不同方向而改变的能量。

- 易磁化轴：饱和磁化响度矢量取不同方向中，能量最低的方向。

- 自旋量子化轴(SAXIS):通过此参数获取旋转角度参数

VASP中的非线性磁性计算的控制参数有三个，分别是：LNONCOLLINEAR, LSORBIT, SAXIS

### 1 LNONCOLLINEAR

LNONCOLLINEAR = .TRUE. | .FALSE. Default: LNONCOLLINEAR = .FALSE. Description: LNONCOLLINEAR specifies whether fully non-collinear magnetic calculations are performed.

设置：LNONCOLLINEAR = .TRUE.

在 INCAR 文件允许执行完全非共线磁结构计算。VASP能够从以前的非磁性或共线计算中读取WAVECAR和 CHGCAR文件，但是不可能在选定的原子上局部旋转磁矩。

因此，在实践中，我们建议分两步执行非共线计算：

- 首先，计算非磁性基态并生成[WAVECAR](https://www.vasp.at/wiki/index.php/WAVECAR)和[CHGCAR](https://www.vasp.at/wiki/index.php/CHGCAR)文件。

- 其次，读取[WAVECAR](https://www.vasp.at/wiki/index.php/WAVECAR)和[CHGCAR](https://www.vasp.at/wiki/index.php/CHGCAR)文件，并通过 MAGMOM 标签提供初始磁矩（比较MAGMOM）。

对于非共线设置，必须为[MAGMOM](https://www.vasp.at/wiki/index.php/MAGMOM)线中的每个离子提供三个值。这三个条目分别对应于每个离子在x，y和z方向上的初始局部磁矩。如：

MAGMOM = 1 0 0 0 1 0

初始化 x 方向上第一个原子的磁矩，y 方向上第二个原子的磁矩。请注意，MAGMOM仅在ICHARG=2时提供初始磁矩，或者CHGCAR文件仅包含电荷而不包含磁化密度。

### 2 LSORBIT

LSORBIT = .TRUE. | .FALSE. Default: LSORBIT = .FALSE. Description: LSORBIT specifies whether spin-orbit coupling is taken into account.

设置LSORBIT=.TRUE.

打开自旋轨道耦合开关(自动设置 LNONCOLLINEAR =.TRUE. 该选项仅适用于PAW赝势，不支持超软赝势。

如果不考虑自旋-轨道耦合，能量不依赖于磁矩的方向，即所有磁矩以相同的角度旋转，原则上得到的能量完全相同。因此，只要不包括自旋-轨道耦合，就没有必要定义自旋量子化轴。

然而，自旋-轨道耦合将自旋耦合到晶体结构上。通过选择开启自旋-轨道耦合:

LSORBIT = .TRUE.

自旋量子化轴可以通过 SAXIS 标签指定：

SAXIS = sx sy sz ! global spin quantisation axis

其中 SAXIS 的默认值为:(0+,0,1)(表示法0+意味着x方向上的一个无穷小的正数)。

现在所有的磁矩都是相对于这个轴 (s_x,s_y,s_z) 给出的。

在这里我们已经采用了这样的惯例: VASP 写出或读出的所有磁矩和旋量都是相对于这个轴给出的。

### 3 SAXIS

由于计算磁各向异性能时都需要重新设置MAGMOM，并且保证模的大小不变，对于磁性原子较多的体系来说，很麻烦。因此VASP指定了非线性自旋的量化轴来简化旋转的操作。

SAXIS= sx sy sz !global spin quantisation axis|default：0+ 0 1

VASP写入或读取的所有磁矩和旋量都是相对于该轴给出的。

这包括[INCAR](https://www.vasp.at/wiki/index.php/INCAR)文件中的[MAGMOM](https://www.vasp.at/wiki/index.php/MAGMOM)线，OUTCAR和PROCAR文件中的总磁化和局部磁化，WAVECAR文件中的类似旋量轨道以及[CHGCAR](https://www.vasp.at/wiki/index.php/CHGCAR)文件中的磁化密度。

- 通过设置自旋量化轴SAXIS，可以确定旋转角度 \alpha,\beta 。（ \alpha 是SAXIS与笛卡尔坐标x之间的夹角， \beta 是SAXIS与笛卡尔坐标z轴的夹角。）

\begin{aligned}\alpha &= {{\rm {atan}}}{\frac {s_{y}}{s_{x}}}\\ \beta &={{\rm {atan}}}{\frac {{\sqrt {s_{x}^{2}+s_{y}^{2}}}}{s_{z}}} \end{aligned}

- 该角度用来旋转参数MAGMOM中的每个原子的磁距\vec{M}^{axis} ，从而得到新的磁距方向 \vec{M} ，并计算该方向上的能量。

旋转规则是：

\left[\begin{matrix} \cos\alpha&-\sin\alpha&0\\ \sin\alpha&\cos\beta&0\\ 0&0&1 \end{matrix} \right] \left[\begin{matrix} \cos\beta&0&\sin\beta\\ 0&1&0\\ -\sin\beta&0&\cos\beta \end{matrix} \right] \left[\begin{matrix} {M}^{axis}_{x}\\ {M}^{axis}_{y}\\ {M}^{axis}_{z} \end{matrix} \right] = \left[\begin{matrix} {M}_{x}\\ {M}_{y}\\ {M}_{z} \end{matrix} \right]

依据这种规则，我们可以发现有两种方式可以将磁距旋转至任意方向：

1. 设置：SAXIS=0 0 1

很容易看出，对于默认值 (s_x,s_y,s_z) = (0+,0,1) ，两个角都为零。

\begin{aligned}m_{x}&=m_{x}^{{{\rm {axis}}}}\\ m_{y}&=m_{y}^{{{\rm {axis}}}}\\ m_{z}&=m_{z}^{{{\rm {axis}}}} \end{aligned}

​ 此时，MAGMOM中设置的方向和大小，就是实际计算的非共线情况下的体系能量。

2. MAGMOM= 0 0 TOTAL M

此时每个原子磁距都是： m^{axis}_{i} = (0,0,m_{i}) ：

\left[\begin{matrix} \cos\alpha&-\sin\alpha&0\\ \sin\alpha&\cos\beta&0\\ 0&0&1 \end{matrix} \right] \left[\begin{matrix} \cos\beta&0&\sin\beta\\ 0&1&0\\ -\sin\beta&0&\cos\beta \end{matrix} \right] \left[\begin{matrix} 0\\ 0\\ {M} \end{matrix} \right] =M \left[\begin{matrix} \cos\alpha\sin\beta \\ \sin\alpha\sin\beta \\ \cos\beta \end{matrix} \right]

此时，旋转后的磁距均与SAXIS的方向平行。因此只需要通过设置其参数即可控制所有原子的方向。

与方法一相比，这种方法计算的自旋方向都是共线的情况，只是空间指向方向可通过SAXIS任意调整。

计算磁各向异性能本身就是共线情况，因此第二种方法更有优势，下面会进行说明。

以上便有两种方法可以使自旋向任意方向旋转，要么通过改变初始磁矩MAGMOM，要么通过改变SAXIS。

为了初始化与所选矢量(x，y，z)平行的磁矩的计算，因此可以指定

MAGMOM = x y z ! local magnetic moment in x,y,z SAXIS = 0 0 1 ! quantisation axis parallel to z

或者：

MAGMOM = 0 0 total_magnetic_moment ! local magnetic moment parallel to SAXIS SAXIS = x y z ! quantization axis parallel to vector (x,y,z)

原则上，两种设置产生的能量应该完全相同，但出于实现原因，第二种方法通常更精确。第二种方法还允许读取先前存在的WAVECAR文件(来自共线或非共线运行) ，并以不同的自旋方向继续计算。当读取非共线WAVECAR 文件时，假设自旋与SAXIS平行(因此 VASP 最初只报告 z 方向的磁矩)。

因此，计算磁各向异性的推荐程序是:

从共线计算开始，计算 WAVECAR 和 CHGCAR 文件。

LSORBIT = .TRUE. ICHARG = 11 ! non selfconsistent run, read CHGCAR LMAXMIX = 4 ! for d-elements increase LMAXMIX to 4, f-elements: LMAXMIX = 6 ! you need to set LMAXMIX already in the collinear calculation SAXIS = x y z ! direction of the magnetic field NBANDS = 2 * number of bands of collinear run

### 计算提示

VASP读取WAVECAR和CHGCAR文件，使自旋量化轴与SAXIS平行，这意味着磁场现在与SAXIS并行，并执行非自洽计算。通过比较不同取向的能量，可以确定磁各向异性。请注意，VASP原则上也可以进行完全自洽的计算（ICHARG=1），但这将允许旋量波函数从其平行于SAXIS的初始方向旋转，直到获得正确的基态，即磁矩平行于易磁化轴。然而，在实践中，这种旋转会很慢，因为自旋的重新定向获得的能量很少。因此，如果收敛准则不太严格，即使对于完全自洽的计算，也可能获得合理的结果（在少数情况下，我们已经尝试过这种方法）。

注意对称性。当选择自旋轨道耦合时，我们建议完全关闭对称性（ISYM=-1）。通常，k点集从一个旋转方向改变到另一个旋转取向，从而恶化了结果的可传递性（如果k点的数量改变，WAVECAR文件也无法正确读取）。

通常，在使用自旋-轨道耦合时要格外小心：能量差很小，k点收敛很慢，而且所需的计算机时间可能是无限的。

建议将GGA_COMPAT设置为FALSE。因为这提高了GGA计算的数值精度。
