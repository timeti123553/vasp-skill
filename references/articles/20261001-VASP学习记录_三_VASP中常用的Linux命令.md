## 1.简单命令

cat xxx：直接在终端输出这个文件的全部内容。

cat -n xxx:也输出全部内容，不过有行标号。

grep A xxx:查找xxx文件中有没有A这个词

mkdir xxx:创建名为xxx的文件夹

cp xxx yyy：把xxx文件复制一次，命名为yyy

rm xxx：删除xxx文件

cp -r xxx yyy：把xxx文件夹复制一次，命名为yyy

rm -r xxx：删除xxx文件夹

mv A xxx：把A移到xxx文件夹，A可以是文件或者文件夹

ls:展现当前目录下的所有内容

ls *：展现展现当前目录下的所有内容及文件夹内的子内容

cd xxx:进入xxx文件夹

## 2.一些复杂的命令

### 2.1 for循环：

for i in {a..b}; do ......; done

举一个例子：

for i in {2..9}; do cp 0.01 0.0$i -r ; done

这里面$的作用据我理解是一个占位符。这一段命令将目录下的0.01复制了8份，分别命名成了0.02-0.09。

注意，这里的a和b只能是整数，并且间隔默认为1。如果想调整间隔，或者任意选择a,b，那么可以使用seq。

for i in $(seq 0.02 0.01 0.05); do cp -r 0.01 $i;done

其中$(seq 0.02 0.01 0.05)的意思是i从0.02，0.03，0.04，0.05中取值。

### 2.2 修改文件内容：

sed -i '3s/0.01/0.02/g' INCAR

-i表示直接对源文件进行修改，3s表示第三行，后面是把0.01改成0.02，g的意思是global全局（行）修改，INCAR说明是对哪个文件进行操作。总体来说，这个命令的效果是将INCAR中的第三行的0.01全部替换成0.02。

如果想同时对多行内容进行修改，比如把3~5行的全部0.01改成0.02，则可以这样：

sed -i '3,5s/0.01/0.02/g' INCAR

## 3.一些其它的小技巧及注意事项

### 3.1 *的用法

grep SIGMA xxx/*/INCAR

上述命令可以在xxx所在的目录下查找所有xxx中的文件夹中的INCAR文件的SIGMA值。*作为通配符（？）在这里起到了依次查找所有下属文件夹的作用。

又比如，你想删除一个文件夹中的所有文件夹：

rm -r *

### 3.2 单双引号

官方介绍如下：

' 单引号，不具有变量置换功能，输出时所见即所得。

" 双引号，具有变量置换功能，解析变量后输出。

我的理解是如果想在''格式内使用变量，那就要把单引号变成双引号。

### 3.3 反选操作

比如当前目录下有命名为1，2，3，4，5，6，7，8，9的5个文件夹，我们只希望保留其中的1和2，如何操作呢？

rm -r !(1|2)

这个时候使用反选就很简单了，注意‘!’的使用还有'|'。

### 3.4 && and ||

一般的使用方法是：

命令1 && 命令2 && 命令3...... 命令1 || 命令2 || 命令3......

与&&的逻辑是从左到右开始执行所有命令直到出现错误，后面的命令不再执行。

或||的逻辑是从左到右开始执行所有命令直到成功执行其中一个，后面的命令不再执行。

### 3.5 变量与{}的组合

如果命令中只出现一个变量，那么变量不用放进{}中。比如将名为0.01的文件夹复制9份，分别命名为0.01-0.09：

for i in {1..9};do cp -r 0.01 $i;done

但如果出现多个变量，或者其它字符，那么就要将变量放入{}中（这里表述可能有点问题）。比如在上面的情况下要命名为111，222，333...

for i in {1..9};do cp -r 0.01 ${i}${i}${i};done
