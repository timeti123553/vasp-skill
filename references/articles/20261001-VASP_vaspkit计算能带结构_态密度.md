0.需要准备的软件：VASP+vaspkit+Originlab

1.静态自洽（scf）

新建一个文件夹scf，按照惯例准备四个输入文件INCAR、POSCAR、KPOINT、POTCAR。

INCAR可以简单设置为如下：

# Basic setup:
ISTART = 0
ICHARG = 2
ISPIN  = 1

# Accuracy controls:
PREC = Normal

# Electronic loop controls:
ALGO  = Normal
EDIFF = 1E-04
NELM  = 60
ISMEAR = 0
SIGMA  = 0.05

# Structure control:
ISIF   = 2
IBRION = -1
NSW    = 0       # 确保这个参数 = 0，才是静态自洽

# Output control:
LCHARG = .TRUE.  # 确保这个是 TRUE（scf 步需要留下 CHGCAR）
LWAVE  = .FALSE.
LELF   = .FALSE.
LVTOT  = .TRUE.  # 顺手写出 LOCPOT，后面取真空能级/功函数要用

其它的文件自己准备~应该都知道怎么做了吧？

2.能带计算

提交任务计算完成之后会有CHGCAR这个文件。新建一个文件夹名字叫band，把scf目录中的INCAR、POSCAR、POTCAR、CHGCAR复制过来。

修改INCAR的内容：

ISTART=1 ICHARG=11 LCHARG = .FALSE. LORBIT=11 # or 10,算投影能带有用

或者复制下面的内容：

# Basic setup:
ISTART = 1       # ⚠️ 见文末「本库注」：scf 没写 WAVECAR 时，这一行其实无效
ICHARG = 11
ISPIN  = 1

# Accuracy controls:
PREC = Normal

# Electronic loop controls:
ALGO  = Normal
EDIFF = 1E-04
NELM  = 60
ISMEAR = 0
SIGMA  = 0.05

# Structure control:
ISIF   = 2
IBRION = -1
NSW    = 0

# Output control:
LCHARG = .FALSE. # ⚠️ 原文此处注释写成「确保是TRUE」，是从 scf 段复制来的残留
LWAVE  = .FALSE.
LELF   = .FALSE.
LVTOT  = .TRUE.
LORBIT = 11      # 或 10；算投影能带时有用

使用vaspkit生成高对称点的KPOINTS文件：

vaspkit

呼出vaspkit界面后直接输入302自动生成二维结构的高对称点路径，输入303生成三维块体结构的高对称点路径。

会生成一个[http://KPATH.in](http://KPATH.in)文件，直接把它cp成KPOINTS文件，然后可以检查修改一下里面的内容：

K-Path Generated by VASPKIT. 60 #这个是高对称点之间的采点数量，我一般会设置高一点，下面都是生成的高对称点以及其坐标。 Line-Mode Reciprocal 0.0000000000 0.0000000000 0.0000000000 GAMMA 0.5000000000 0.0000000000 0.0000000000 M 0.5000000000 0.0000000000 0.0000000000 M 0.3333333333 0.3333333333 0.0000000000 K 0.3333333333 0.3333333333 0.0000000000 K 0.0000000000 0.0000000000 0.0000000000 GAMMA

之后再次提交计算。

3.导出作图数据

再次呼出vaspkit，直接输入211，即可生成可以导入OriginLab中绘图的数据BAND.dat。

当然这里也可以选择生成投影能带的数据，看选择的是212还是213还是214还是215还是216了。

对了带隙可以在BAND_GAP文件里面查看。

4.OriginLab绘图

把BAND.dat下载下来，拖进OriginLab里面。

点击绘图->折线图

注意BAND.dat，BAND_GAP，KLABELS里面的信息，不然画不出图。

画图步骤略。

5.态密度计算

和计算能带的做法一样，先新建一个目录，命名为dos，然后复制scf目录里面的INCAR、POSCAR、POTCAR、KPOINTS，CHGCAR过来。要修改一下INCAR，或者直接复制下面的INCAR。

INCAR:

# Basic setup:
ISTART = 1
ICHARG = 11
ISPIN  = 1

# Accuracy controls:
PREC = Normal

# Electronic loop controls:
ALGO  = Normal
EDIFF = 1E-04
NELM  = 60
ISMEAR = -5
SIGMA  = 0.05

# Structure control:
ISIF   = 2
IBRION = -1
NSW    = 0

# Output control:
LCHARG = .TRUE.
LWAVE  = .FALSE.
LELF   = .FALSE.
LVTOT  = .TRUE.

#DensityOfStates control:
EMIN  = -10      # 按能带的能量范围来定
EMAX  = 10
NEDOS = 801      # DOS 采点个数，弄高一点无所谓
LORBIT = 11

KPOINTS要设置得比原来做scf的时候要高，高多少自己看着办咯。我一般设成SCF计算的两倍，20-40之间。其他的输入文件不用改。

6.导出DOS数据+导入OriginLab绘图

召唤vaspkit！输入111即可导出TDOS.dat文件，用于绘制DOS图。过程我略略略！

## 本库注（收录时补充，非原文内容）

### 一、原文一处自相矛盾（评论区也有人问到）
能带 INCAR 里 `LCHARG = .FALSE.`，但**同一行的注释却写着「确保这个是 TRUE」**——那是从 `scf` 段复制过来的残留。**非自洽的能带/DOS 步不需要再写 `CHGCAR`，`LCHARG` 用 `.FALSE.` 即可**；写成 `TRUE` 只是多产生一个大文件。

### 二、评论区三条高频疑问（本库已有答案，已提炼进 `workflows.md` 第三节）
1. **「`scf` 没输出 `WAVECAR`，为什么能带步要写 `ISTART=1`？」**（两位读者先后问到）
   —— 目录里没有 `WAVECAR`，**这一行会被 VASP 忽略**；**最简洁且无歧义的组合是 `ISTART = 0` + `ICHARG = 11`**（只读 `CHGCAR`）。原文的 `ISTART=1` 属于冗余写法。
2. **「用 vaspkit 导出的能带数据，费米能级自动归零了吗？要不要手动减？」**
   —— **已经默认归到 0**，不需要手动减（另一篇讲 DOS/Origin 的文章也确认了这点）。
3. **「能带计算完，`vaspkit 211` 不输出 `BAND_GAP` 是怎么回事？」**
   —— 本库暂无经过验证的结论，但可先排查：**任务是否真的正常结束**、目录里是否有 `EIGENVAL`/`OUTCAR`、**VASPKIT 版本是否太旧（`BAND_GAP` 是新版才有的输出）**、以及**体系是否为金属**（无带隙时该文件可能不生成或为 0）。以上为排查方向，非原文结论。
4. **「设了 `LORBIT=11` 却没有 `PROCAR`？」**
   —— `PROCAR` 是**在计算结束时才写出**的，**最常见的原因是任务没跑完/中途退出**；其次确认 `LORBIT ≥ 10`（`11` 不需要 `RWIGS`）并且用的是普通版本（非 `vasp_gam`）。
5. **「这种写法用的什么泛函？」**
   —— INCAR 里没有 `GGA` 标签，**泛函由 `POTCAR` 决定**（库内教程默认 PBE）；想确认就跑完 `grep TIT OUTCAR` / 看 `POTCAR` 第二行。

### 三、其它
- 原文 DOS 步的 `LCHARG` 写的是 `.TRUE.`（能带步写 `.FALSE.`）——**两者都能算**，只是多写一个 `CHGCAR`；要统一的话，**非自洽步都用 `.FALSE.` 更省空间**。
- 原文在 `scf` 步就打开了 `LVTOT=.TRUE.`（写 `LOCPOT`）——**这是好习惯**：功函数/真空能级对齐/形变势都要用它，等到需要时再补算就要重跑一遍。
