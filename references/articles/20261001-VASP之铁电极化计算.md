- 1. 极化强度计算

首先选取极化相FE（PhaseB, P, 铁电相）和参考相NP（PhaseA, P=0, 中心对称相），分别以下列INCAR计算，

SYSTEM = FE
ENCUT  = 600           # 铁电极化计算建议设置高精度
EDIFF  = 1E-6
IBRION = -1
POTIM  = 0.3
NSW    = 0
EDIFFG = -5E-3
ISMEAR = 0
SIGMA  = 0.05
PREC   = Accurate
ISIF   = 2
#NPAR  = 4
LWAVE  = .FALSE.
LCHARG = .FALSE.
LREAL  = .FALSE.
LDIPOL = .T.           # ⚠️⚠️ 本库注：不要这么写（评论区的关键更正），应改为显式 IDIPOL
DIPOL  = 0.2 0.2 0.2   # 不要设置在原子及迁移路径上，设置在真空层的一边/质心
IDIPOL = 3             # 只沿 z（真空/极化）方向做偶极修正
LCALCPOL = .TRUE.      # 计算铁电极化开关

收集结果：grep "Total electronic dipole momen" OUTCAR & grep "Ionic dipole moment" OUTCAR，离子与电子相加即可，然后用NP相-铁电相即可得到极化强度P，注意单位换算。

注意：

在铁电极化计算过程中经常会出现参考相为非半导体的情况，这种情况下可以：①镜像法：以FE以NP为参照中心，建立一个-FE相（PhaseB’, 即铁电极化方向相反）。然后按照上述方法计算极化，再以FE相的极化-（-FE相）的极化值，然后除以2即得到极化强度。可以理解为1-（-1）=2，2/2=1；②线性插值法：在FE和NP相中间插入一系列中间过渡相（0%（FE）,10%,20%,30%....100%(NP)），计算它们的极化，然后可以用Origin做拟合，100%时即为NP相的极化。（100%-0%）则是极化强度P。

- 2.1 L-G公式系数A, B和C计算

分别计算各个原子位移（原子移动方式可以类似于线性插值法）后结构的极化值，通过L-G公式拟合极化与能量得到前三项的系数A,B和C。

- 2.2 L-G公式系数D计算

由具有铁电性的原胞（FE结构）建立441超胞，计算超胞能量E1。然后将441超胞中其中一个原胞的FE结构换成-FE结构（-FE结构），代表一个dipole发生了翻转，计算出超胞能量E2，根据朗道有效哈密顿量在这两种情况下的表达式，并比较能量E1和E2，就可以得到D的数值。

- 3. 居里温度计算的两种方法

- 3.1. AIMD方法计算居里温度Tc（计算量巨大，准确）

使用AIMD分别计算不同温度下的超胞，通过统计学得到平均极化距离d，通过d找到对应温度下的极化值，然后通过slogical1函数拟合得到Tc。

- 3.2. MC方法计算居里温度Tc（计算速度极快，建议）

通过L-G公式进行拟合即可，代码及教程详细可看

## 本库注（收录时补充，非原文内容）

### 一、评论区的一条**关键技术更正**（比正文更重要）
一位读者指出：**「一定不能定义 `LDIPOL=T`，要默认 `LDIPOL=F`」**——因为 `LDIPOL=T` 时**默认等价于 `IDIPOL=4`**，会让 VASP 按「偶极中心」自行判断一个**任意方向**的偶极并在该周期方向做修正，**等于在周期性方向上加了一个任意电场**，既容易算错又收敛很慢。
**正确做法：显式写 `DIPOL` + `IDIPOL=3`（真空/极化方向）**，不要打开 `LDIPOL`。
（下文正文里的 `LDIPOL = .T.` 一行因此**保留原样但已加警示**；提炼进本库时用的是更正后的写法，见 `workflows.md` §31.1/§31.2 与 `references/incar.md` §二附4。）

### 二、一处单位笔误（读者更正）
原文单位换算写成 `eÅ = C/m`，**应为 `eÅ = C·m`**（偶极矩 = 电荷 × 长度）。

### 三、评论区反复出现、本库已有答案的问题
1. **「某个结构算出来三个方向的偶极矩都不为 0，怎么判断极化方向？」**
   —— ⚠️ **单独一个相的 `p[ion]`/`p[elc]` 没有物理意义**：它依赖原点选取，而且只确定到**极化量子**的整数倍。**必须与参考相（NP，或镜像相 −FE）相减**，才谈得上极化强度与方向（`workflows.md` §31.1–31.3、`errors`/§二十三 的极化量子说明）。
2. **「怎么找 NP 相（中心对称参考相）？」**
   —— 通用做法：把 FE 相中造成极化的那组原子**移到中心对称位置**（例如把位移归零），并**确认其空间群含反演中心**；两相必须用**同一套 `ENCUT`/`KPOINTS`/`POTCAR`/晶胞**，只改原子位置。
3. **「磁性材料的 `Spin resolved dipole moment` 要不要一起加？」**
   —— **取 `Total electronic dipole moment` 与 `Ionic dipole moment` 两行即可**；`Spin resolved` 是把电子部分按自旋分解出来的补充信息，不重复相加。
4. **「什么情况下要考虑极化量子？」**
   —— Berry phase 给出的极化只能确定到 `e·R/Ω` 的整数倍；**当两相之差超过半个量子时**就必须选择分支/用 31.3 的插值法把路径连起来。

### 四、尚未回答的问题（留作以后补）
「系数 D 是不是就用 `E1`、`E2` 的差值？」「取 pz 轴偶极矩时为什么选中间一列数据？」—— 原文与评论区都没有给出明确答复，本库暂不做推断。
