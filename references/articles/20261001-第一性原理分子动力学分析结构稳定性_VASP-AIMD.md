利用VASP进行结构的热力学稳定性验证

官方参考指南：Liquid Si - Standard MD

[Liquid Si - Standard MDwww.vasp.at/wiki/index.php/Liquid_Si_-_Standard_MD](https://www.vasp.at/wiki/index.php/Liquid_Si_-_Standard_MD)

验证结构稳定性的方法很多，比如计算声子色散、热浴等等，今天介绍使用VASP的分子动力学模块（AIMD），利用第一性原理分子动力学进行结构热力学稳定性的验证。

一、准备所需文件

- KPOINTS

#KPOINTS 0 Gamma 1 1 1 0.0 0.0 0.0

因为分子动力学所需的模型比较大，所以只需要k点都设置为1即可

2. POSCAR

分子动力学的模型应该尽量大一些，扩胞到至少100个原子以上

3. INCAR

这里我们使用Andersen thermostat在NVT系综下进行热浴，其他热浴方式以及系综可查看官网手册：

https://www.vasp.at/wiki/index.php/MDALGO

ISMEAR = 0 IBRION = 0 # Molecular dynamic ISIF =3 MDALGO = 1 # Anderen thermostat ANDERSEN_PROB = 0.5 SIGMA = 0.1 LREAL = Auto ALGO = Fast PREC = Normal ISYM = 0 TEBEG = 1000 # beginning temperature TEEND = 1000 # ending temperature NSW = 3000 # total steps POTIM = 3 # timestep(fs) NCORE = 8 # parallel groups

注：

i. TEBEG和TEEND决定了你的热浴温度

ii. 至少跑10ps

4. POTCAR 不赘述

二、运行VASP，得到OUTCAR

运行以下命令，得到整个过程的能量变化

grep "free energy" OUTCAR|awk ' {print $5}' > energy.dat

三、绘图分析

可以从图像中看出，能量虽然有波动但是比较稳定，所以说明该结构在1000K温度下还是稳定的。另外，将计算得到的CONTCAR导入到ovito中可以看出结构有所变化，但并没有破坏。
