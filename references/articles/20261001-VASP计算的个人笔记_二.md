波恩有效电荷，一个很神奇的东西，其实该怎么计算在VASP的说明书上有很详细的解释。

而且，说明书上还有一个算例呢，按理来讲照着它的算例做一遍，基本上就知道该怎么计算了。

不过可能因为我看的说明书是旧版的，并没有介绍LCALCPOL 的使用。

明明计算一遍就够了，还要自己计算三遍然后加加减减，难道他们写说明书的时候，就不会考虑到，他们的用户有可能不会加减法么。

万一某一天人类灭绝，猩猩统治世界的话，当它们看到废墟中的VASP说明书与VASP软件的时候，它们该怎么计算波恩有效电荷呢。

言归正传

首先优化一下晶格常数。

其次，静态计算，将IBRION设置为-1 NSW设置为0

需要注意的是，LCHARG要设置成为True，它的意思是，要把电荷相关的文件输出出来。

当然，可能有些人选择不输出它是因为硬盘空间不够大，但是呢，如果硬盘空间足够大（换言之还没有被奇奇怪怪的东西塞满的话），那就始终输出好了，谁知道什么时候用得到什么时候用不到呢。

值得一提的是，ISIF在这里被我设置成了2，我也不知道为什么这么设置，不这么设置也是可以的，可能写INCAR文件的时候，写错了吧，但反正IBRION都已经是-1了，这个怎么设置都无所谓了。

静态计算完后，把CHG,CHGCAR,WAVECAR这三个文件拷贝出来，加入到新的计算里面。

也就是说，下一步的计算过程中，有7个输入文件，INCAR POSCAR, POTCAR KPOINT CHG CHGCAR WAVECAR。

外加一个脚本文件vasp.pbs，以及一个求它计算结果正确的祈祷文件,pray.txt（祷告词的话，你们随意写好了）

这个INCAR文件里面贴在下面

EDIFF = 1.0E-06 eV

PREC = High

NELM = 200

NELMIN = 2

NSW = 0

IBRION = -1

ISMEAR = 0

ISIF = 2

EDIFFG = -0.005

SIGMA = 0.05

POTIM = 0.2

LCHARG = .T

NPAR = 4

LREAL = Auto

LBERRY = .T

LCALCPOL = .T

NPPSTR = 2

DIPOL = 0.25 0.25 0.25

注意DIPOL好像虽说可以随便设置，但是不要放到某一个原子的上面，更不要让某一个原子在移动过后会穿过这个DIPOL。（我也不知道穿过会怎样，反正说明书上说不要这么干）

然后呢，POSCAR要移动一下原子，比如要计算的是一个Ti原子的波恩有效电荷，那么久移动一下Ti原子，随后在OUTCAR中ctrl+f Ionic dipole moment

如果觉得计算一次不够的话，可以每次移动不同大小的Ti原子，多次计算拟合出来一条直线也行。这样计算好像还有一种什么称呼来着。总之在小木虫上以前看到过被人说这种计算方法，尽管当时我没看懂，但后来翻译成为白话文后，稍微理解一下，就是多计算几个点拟合曲线嘛。

对了，这里面计算出来的波恩有效电荷，和上一个笔记里面写的那个计算出来的原子移动，乘一下，就是极化了。

我之前还一直以为极化是一个可以直接输出的东西呢。没想到居然还要用到乘法。还是为那些加减法都没学好的人默哀一分钟吧。
