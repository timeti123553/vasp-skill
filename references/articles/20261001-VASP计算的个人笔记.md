言归正传，题图里面的那个东西怎么计算呢？（P.R.B.49.5828）

以BaTiO3为例子，首先构建POTCAR，然后弄一个立方的晶格，然后弄一个KPOINT文件。

令ISIF=3，IBRION=2，EDIFF，ENCUT和EDIFFG看心情设置，NSW设置为一个大一点的数（如果等的起的话，设置成100000000也不是不可以，然后这段时间可以打打游戏看看剧，顺便当老师问起计算怎么样的时候，就可以甩锅给服务器——不是我不干活，实在是等计算结果要等好久好久…）

这样呢，能计算得到一个晶格常数，计算结果的CONTCAR会发现，各个原子还在对称点上（其实我也不知道应不应该叫它对称点，反正就是指，Ba 0,0,0 Ti 0.5,0.5,0.5之类的意思吧），只是晶格常数发生了改变，这就是优化晶格常数得到的结果。顺便提一句，优化的英文单词是optimize。

接下来，稍微移动一点点每个原子在c方向上的位置，比如，可以把Ba的0 0 0 改成 0 0 0.01

因为，VASP计算后的结果的样子和计算之前这么移动是有些关系的。比如如果初始是0 0 0,那么结束的时候一定是0 0 0，VASP才不会自己帮你优化。 但是，一旦改成了0 0 0.01, 那么结尾就可能是 0 0 0.04，简而言之，你不推它一下，它自己懒得动弹。

接下来，INCAR文件中的ISIF改为2，于是计算出来的结果中的CONTCAR如下。
