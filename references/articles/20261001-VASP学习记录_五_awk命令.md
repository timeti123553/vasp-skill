老师给的服务器出了点问题，只能写点其它相关的了。awk是一种处理文本文件的语言，是一个强大的文本分析工具，也可以作为数据处理的利器。知乎上已经有非常好的相关教学，比如：[机智的程序员小熊：Linux三剑客老大 awk](https://zhuanlan.zhihu.com/p/68188159)，[龙叔运维：linux-命令-awk（运维基本功）](https://zhuanlan.zhihu.com/p/324580730)。这里我结合自己的一些理解写一些东西。

awk的通用方式：

awk [-F分隔符] [-v 变量=值] ‘BEGIN { 初始化 } { 循环执行部分 } END { 结束处理 }’ file1 file2...

需要注意的是，分隔符，变量，初始化，循环执行部分，结束处理，文件 都不是必须的，如果没有可以不写。后面的文件可以有一个或者多个。

直接给一个例子：

我们的文本是（文本命名为grade）：

PONY 12 98 32 XINGTONG 32 99 101 ALAN 98 45 76

命令是（为了方便观看使用\将各部分分开）：

awk 'BEGIN{print "姓名 语文 数学 英语 总成绩";sum1=0;sum2=0;sum3=0;sumall=0;}\ {print $1,$2,$3,$4,$2+$3+$4;sum1+=$2;sum2+=$3;sum3+=$4;sumall+=$2+$3+$4}\ END{printf "总成绩",sum1,sum2,sum3,sumall}' grade | column -t

输出是：

这里awk后面直接是BEGIN，命令行选项使用的是默认值。

BEGIN中的命令是在读取数据之前执行，例子中是使用print输出了第一行并且预设了局部变量为0.

命令的第二行是循环执行部分。我觉得可以理解成省略了一个对行执行的for循环。$1~$n的意思是按照分割符分割之后第一列数据，第二列等依次类推。例子的第一句是依次输出每一行的第一列、第二列、第三列、第四列，以及234列之和；后面则是对BEGIN中设置局部变量进行处理，这也是循环执行的。

END中的命令是在读完所有数据后执行。例子中是输出了三个人语文、数学、英语、总成绩的总和。

最后的grade是文本文件的名称，column -t是一个对齐的操作。

下面使用另一个例子介绍分隔符：

$ echo '192.168.1.1' | awk -F "." '{print $2}' 168

其中echo是字符串输出命令，|是管道命令，将其左边的输出传递为右边的输入。在这个例子中，分隔符从默认的空格被设置为"."，于是$2就是最后输出的168。如果仍使用默认的空格，不会有输出。

awk还自带一些默认变量：

NF：每行被分割之后的字段数量

NR：awk读取的行数

FNR：当前读取的记录数，不同于NR，因为当awk读取第二个文件的时候，FNR就会从0开始，但是NR会继续递增

RS：输入文件的行分隔符，默认是换行符

FS：分割字符，默认是空格和TAB

awk '{print NF,NR}' grade 4 1 4 2 4 3

一些高级操作：

1.三元运算符（表达式?动作1:动作2）

awk 'BEGIN{a=2;print a==1?"ok":"no ok";}' no ok

上面这个例子中a==1?"ok":"no ok"作为一个整体，用来判断a是否等于1。

数据处理实例：

1.求十个数据的总和与平均值，文件名为data。

awk 'BEGIN{sum=0;average=0}{sum+=$1}END{average=sum/NR;print "sum="sum,"averagr="average}' data sum=284 averagr=25.8182
