在刚接触VASP的时候，我们把这个软件当成一个黑盒子就行了。试想你开车上班，难道需要了解汽车的每一处构造吗？会开就行了。（不过自然是了解的越清楚越好，我老板就说他学习时把源码看完了，不过这个到时候再说。）我们首先要知道这个黑盒子的输入有四个，INCAR，KPOINTS，POSCAR，POTCAR。这里提一句，windows推荐使用Notepad++进行操作，据说使用记事本会出问题，不过我也懒得试了。最后导出的输入文件是没有后缀名的。

我们从实践中学习，虽然目前什么都不会，但这并不妨碍我们使用VASP！首先输入文件大概来说就是：

- INCAR 告诉VASP算什么，怎么算。

- KPOINTS 包含计算的K点信息。

- POSCAR是计算模型结构的文字描述，也就是各个原子在xyz方向的坐标信息。

- POTCAR对应的是计算过程中每个原子的平面波基组，描述体系中对应的原子核和电子的相关信息。

此外，一般来说还有提交任务的脚本或者命令，需要你自己准备，建议去问你们的老板具体怎么提交。以我的情况为例，就是四个输入文件加一个提交文件放进一个文件夹，然后一个提交命令就搞定。

下面我们在具体的例子中展示，我们使用官网所给的例子-氧原子。我们先不管这些输入文件究竟写的都是什么含义，先写好扔进VASP再说。

INCAR

SYSTEM = O atom ISMEAR = 0 SIGMA = 0.01 ISPIN = 2

第一行解释系统在算什么，与计算无关。第二行和第三行是展宽方法和参数（？），记得ISMEAR在分子原子计算时候取0就行了，而对于SIGMA:

- 如果用了ISMEAR = -5； SIGMA的值可以忽略，也可以不管。

- 对于金属： ISMEAR = 1 或者0，非金属: ISMEAR= 0 的时候，一般取 SIGMA = 0.10 即可，默认值是0.20。不放心的话，用0.05。

- 对于气体分子，原子体系：死死记住下面组合就可以了， ISMEAR = 0; SIGMA = 0.01。我们就是这种情况。

第四行是考虑自旋极化，因为氧原子具有磁性。ISPIN取1或2，1是默认值，代表不考虑自旋极化；取2则是考虑极化。当体系为单原子、氧分子、含铁钴镍时一般需要考虑这一项。

KPOINTS

K-POINTS 0 Gamma 1 1 1 0 0 0

KPOINTS设置了布里渊区网格取样大小或能带结构计算时沿着高对称方向的K点。

第一行随便写，但不能没有。第二行0表示自动生成K点；第三行这个只认首字母，写个g也行，表示以gamma点为中心生成网络。第四行是在xyz三个方向上生成对应数目的K点，对于原子或者分子是111;第五行一帮0 0 0。

POSCAR

O atom in a box 1.0 7.5 0.0 0.0 0.0 8.0 0.0 0.0 0.0 8.9 O 1 Cartesian 0 0 0

POSCAR描述计算体系的晶胞参数，原子个数以及位置。

第一行随便写，但不能没有。第二行：Scale factor，称为缩放系数，这里是1.0；第三到五行：是组成格子的三条边的坐标信息；这里三个方向的大小不同，是为了降低系统对称性（？）。

第六行：体系中的元素，这里我们算的是氧原子，所以写：O，即氧的元素符号。需要注意的有以下几点：

- vasp4.xx版本里面没有这一行，不过现在几乎没人用4.X的版本了；

- O的符号和数字0容易混淆，一定要注意；

- 第一个元素符号要顶格写，前面不要有空格，有可能会出错；

- 如果计算文件夹里面，已经有与结构相一致的POTCAR，那么POSCAR里面即使删了这一行有不会影响计算，VASP会读取POTCAR中的元素信息，但输出文件CONTCAR中会把该行自动加上。

- 第七行：与第六行中元素相对应的原子数目，这里我们只有1个氧原子，所以写成1；

第八行：体系中原子的坐标系，可以为笛卡尔坐标，也可以为分数坐标系。注意的有以下几点：

- 这一行同KPOINTS的第三行一样，即只认第一个字母；

- C或者c代表笛卡尔坐标， D或者d代表分数坐标系；

- VASP输出文件CONTCAR里面采用的是分数坐标系。

- 第九行：体系中原子的坐标信息。这里我们把O原子放到了原点（0.0 0.0 0.0）的位置，大家也可以随便放一个位置，比如：（4.0 5.0 6.0），（1.1 2.5 6.5）都是可以的。由于周期性的存在，不管你怎么放，相邻两个格子之间氧原子的距离都是一样的。

POTCAR

POTCAR是赝势文件。这个我就不给了，不是我偷懒，而是有2000+行。通常VASP软件包里都有各个元素的POTCAR，大家自行查找吧，选第一行是 PAW_PBE O 08Apr2002 的那个就行。

把四个文件成功提交以后等几分钟估计就行了，文件夹里会多出一堆输出文件。
