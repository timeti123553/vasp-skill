# INCAR 参数速查（查"这个参数是什么意思、该取什么值"）

> **本页只做查阅**。具体流程里怎么配，看 `workflows.md` 对应小节；报错怎么调，看 `errors.md`；
> 并行与效率（`NCORE`/`NPAR`/`KPAR`），看 `references/performance.md`；赝势与泛函选择，看 `references/onboarding.md` §3。
> 主要整理自《VASP 参数含义》（`articles/20261001-VASP参数含义.md`，对应 **opt** 阶段），
> 原文的「黑色=常用 / 蓝色=不常用」着色在抓取后丢失，本页统一用表格，并标注了原文笔误与库内印证。

## 一、全局（Global）

| 参数 | 常用取值 | 含义与经验 |
| --- | --- | --- |
| `ISTART` | `0` / `1` / `2` | 是否读入 `WAVECAR`：`0` 从头算（不读）；`1` 读入并继续（**胞的形状/大小、截断能都可以变**）；`2` 读入但**截断能与胞都不能变**。有默认行为（找不到 `WAVECAR` → `0`，否则 `1`），**通常不用手动设** |
| `ISPIN` | `1` / `2` | 自旋极化开关：默认 `1`（非磁），`2` 做自旋极化。做**非共线**（`LNONCOLLINEAR=.TRUE.`）时**不必设** `ISPIN` |
| `ICHARG` | `0` / `1` / `2` / `11`（另有 `10`、`12`） | 初始电荷密度来源：`0` 由初始轨道算；`1` 读 `CHGCAR` 后**继续自洽**；`2` **原子密度叠加**起步；**`11` 读入电荷密度做非自洽**（能带/DOS，密度保持不变）。⚠️ 非自洽、尤其 **DFT+U** 时设 **`LMAXMIX=4`（d）/`6`（f）** |
| `ENCUT` | 默认 = POTCAR 里最大的 `ENMAX` | 平面波截断能，决定基组大小与精度；**建议显式写**并做收敛测试（见 `workflows.md` §二十八）；**一般取默认值的 1.3 倍**；**变胞优化时更要提高** |
| `PREC` | `Normal` / `Accurate` | 会影响 `ENCUT`、`NGX/NGY/NGZ` 等；一般 `Normal`；**声子等高精度计算用 `Accurate`** |
| `LREAL` | `.FALSE.` / `Auto` | 投影算符在倒空间还是实空间：高精度用 `.FALSE.`；**> 20 个原子可用 `Auto`**；关注**极小带隙（meV）或磁各向异性能（μeV）必须 `.FALSE.`** |
| `ALGO` | `Normal` / `Fast` / `VeryFast` / `All` / `Damped` / `Exact` | 电子步算法：`Normal`=blocked Davidson；`VeryFast`=RMM-DIIS；`Fast`=先 Davidson 后转 RMM-DIIS；`All`/`Conjugate`=共轭梯度；`Exact`=严格对角化。**快与稳的取舍见 `errors.md` §2.6** |
| `AMIX` / `BMIX` / `AMIX_MAG` / `BMIX_MAG` | 金属 `AMIX≈0.02`；半导体 `AMIX≈0.2`；`BMIX≈0.0001`；磁性体系常用 `AMIX_MAG=0.8`、`BMIX_MAG=0.0001` | 电荷/磁矩混合参数；设 `BMIX`/`BMIX_MAG` 可打开线性混合。⚠️ **磁性金属里 `AMIX` 过大会「收敛到更高的磁态」（能量更高的错误态）**，且可用 `AMIX_opt = AMIX_current × Γ`（Γ 取 `OUTCAR` 的 `average eigenvalue`）来优化——详见 `errors.md` §2.6 |
| `GGA` | `PE`（= PBE） | 泛函选择；与赝势目录的对应关系见 `onboarding.md` §3.2 |
| `LNONCOLLINEAR` | `.TRUE.` / `.FALSE.` | 非共线磁结构计算；**可以不配自旋轨道耦合** |

## 二、电子步（Electronic Relaxation）

| 参数 | 常用取值 | 含义与经验 |
| --- | --- | --- |
| `ISMEAR` / `SIGMA` | 半导体/绝缘体 `0` + `0.05`；金属 `1`/`2` + `0.2`；DOS/高精度总能 `-5`（不设 `SIGMA`） | 布里渊区积分的展宽方式：`0` 高斯展宽；`1`/`2` Methfessel-Paxton（**金属**，取 `SIGMA≈0.2` 使熵项 < 1 meV/atom）；**半导体/绝缘体避免 `ISMEAR>0`**；`-5` 四面体法适合高精度总能与 DOS，但**k 点极少（1~2 个）或一维体系不适用**，且**金属做结构优化会有明显力的误差（原文给 5%~10%）**——与 `errors.md` §2.1 的结论一致 |
| `NELM` | 默认 `60`，常设 `100` | 电子自洽**最大**步数（结构优化/MD 可更大） |
| `NELMIN` | 默认 `2`；MD/优化可 `4~8` | 电子自洽**最小**步数 |
| `NELMDL` | **建议取负值** | 非自洽延迟步数：正值表示每次自洽都延迟更新电荷密度，负值表示只第一次延迟；默认 `-5`/`-12`/`0` |
| `EDIFF` | `1E-6`（默认 `1E-4`） | 自洽收敛判据：前后两次总能差小于它即认为收敛 |

### 二附、杂化泛函（HSE06）的电子步参数

跑 **HSE06** 时除了常规电子步参数，还要加这几个（完整流程见 `workflows.md` 第二十九节）：

| 参数 | 常用值 | 说明 |
| --- | --- | --- |
| `LHFCALC` | `.TRUE.` | 打开杂化泛函（Hartree-Fock 型精确交换） |
| `HFSCREEN` | `0.2` | 屏蔽长度（`0.2` Å⁻¹ 即 **HSE06**；`0` 则为 PBE0） |
| `AEXX` | `0.25` | 交换泛函中精确交换的混合比例 |
| `LMAXFOCK` | `4` | HF 部分在 PAW 球内的**增广**（augmentation）阶数；社区常用 `4` |
| `PRECFOCK` | `Fast` | 精确交换部分的 FFT 网格精度；**想更准可以收紧** |
| `ALGO` | `Damped`（或 `D`） | 杂化的稳定算法 |
| `TIME` | `0.4` | 与 `ALGO=Damped` 配套的步长控制 |
| `LDIAG` | `.TRUE.` | 子空间对角化 |
| `EDIFF` | `1.E-6` | 杂化对电子步精度更敏感 |
| `ISTART` / `ICHARG` | `1` / `1` | **读入纯泛函（PBE）算出的 `WAVECAR`** 并据此重算电荷——这是 HSE 能带的关键（否则导带出现锯齿） |


**HSE 参数的官方语义补充**（默认值与可选档位）：

- **`LHFCALC`**：默认 `.FALSE.`（打开才会做 HF 型精确交换）；
- **`AEXX`**：**`LHFCALC=.TRUE.` 时默认 `0.25`；`.FALSE.` 时默认 `0`**——代表交换能中精确交换的分数；
- **`HFSCREEN`**：**`0.2` → HSE06；`0.3` → HSE03**（在 PBE 势上把长程 Fock 交换换成屏蔽形式；`0` 则得到 PBE0）；
- **`ALGO`**：默认 `Normal`；做杂化时常见写法是 **`Damped`/`D`**（配 `TIME=0.4`）或 **`ALL`（= `ALGO=58`）**，
  两种都能跑；
- **`TIME`**：默认 `0.4`——控制 `IALGO=5X` 的**试验时间步长**（只在初始最陡下降阶段起作用）；
- **`PRECFOCK`**：`Low | Medium | Fast | Normal | Accurate`，默认 `Normal`——**精确交换部分的 FFT 网格**，
  允许与局域 Hartree/DFT 电势用**不同**的网格；
- **`NKRED`（及 `NKREDX`/`NKREDY`/`NKREDZ`）**：**只在 q 点的子网格上计算 HF 核**——用来加速，
  但要注意"只对偶数 k 网格有效"（用错会引入误差，非高手不要乱开）；
- **`HFLMAX`**：HF 部分的截断（注释里常见 `4`，即 4d、6f）；
- **`LDIAG`**：默认 `.TRUE.`，执行子空间旋转（对角化）；
- **`ISTART` 的 0/1/2/3 语义**（读波函数时很关键）：`0` 无 `WAVECAR` 时按 `INIWAV` 初始化；
  **`1` 读 `WAVECAR` 但平面波基组会随新的晶胞/`ENCUT` 更新**；**`2` 读 `WAVECAR` 且平面波基组不变**
  （算体积-能量曲线时用）；**`3` 重启分子动力学（同时需要 `WAVECAR` 与 `CHGCAR`）**。

⚠️ 已知冲突：**HSE 不能与 `ISMEAR=-2` 一起用（会崩成 NaN）**，见 `errors.md` §8.8；HSE 的 `BUG card` 见 §8.9。

### 二附3、几个高频参数的"官方语义"补充

| 参数 | 默认 | 要点 |
| --- | --- | --- |
| `PREC` | `Accurate` | **只有在 INCAR 未给 `ENCUT` 时才由它决定截断能**（`PREC=High` 时 `ENCUT = POTCAR 的 1.3 倍`）。**它控制的参数有四类：`ENCUT`；`NGX/NGY/NGZ`；`NGXF/NGYF/NGZF`；`ROPT`**——设了 `PREC` 这些都不用写，反过来直接写这些参数效果相同（**与 §8.14 的 FFT 网格报错直接相关**） |
| `LREAL` | `.FALSE.`（小体系） | 四档：`.FALSE.` 倒空间投影；`.TRUE.` 实空间（最简单地分离高频组分）；**`On`/`O`** 用优化过的实空间算符；**`Auto`/`A`** 更好的优化——**一般原子数 >20 才考虑用实空间投影（老版本阈值 20、新版本 30）** |
| `SIGMA` | `0.2` | **`ISMEAR=-5` 时该值无影响** |
| `ISMEAR` | `1`（VASP 默认） | `>0` N 阶 Methfessel-Paxton（**部分占有率可能为负或 >1，可能让绝缘体算错**）；`0` 高斯；`-1` 费米；`-2` 从 `WAVECAR`/`INVO` 读占有率并固定；`-3` 循环展宽参数；**`-4` 不带 Bloch 修正的四面体；`-5` 带 Bloch 修正的四面体** |
| `EDIFF` | `1E-4` | 判据是**两步的"总能量**与**能量本征值"差值都小于设定值**；高精度（如声子）建议 `1E-6`~`1E-7` |
| `EDIFFG` | `EDIFF × 10` | 正 = 能量变化判据（eV）；负 = 力判据（eV/Å，比较绝对值） |
| `NEDOS` | `301` | DOS 横轴（Energy）的取点数量 |
| `LORBIT` | — | `0/1/2/5/10/11/12`；**结合 `RWIGS` 决定是否输出 `PROCAR`/`PROOUT`**，**≥10 时不需要 `RWIGS`**；**一般用 `11`**，输出投影到各原子各轨道的分波态密度 |
| `MAGMOM` | — | 格式：逐原子 `m1 m2 …`、重复式 `n*m`（如 `2*5 2*0 6*0`）、**长串可用反斜杠 `\` 续行**；**非共线时每原子 3 个分量**（如 `1 0 0 0 1 0`）。写法要点：**值不必精确，但建议取预期磁矩 × `1.2~1.5`**（更易收敛到目标磁基态）；**只设 `ISPIN=2` 而不写 `MAGMOM` 时，VASP 给每个原子默认加 `1`**；⚠️ **它只在 `ICHARG=2`、或 `CHGCAR` 不含磁化密度时才作为初猜生效**；**最终磁态强烈依赖初值（即使 `ISYM=-1`）**——详见 `workflows.md` §三十五、§33.7 |
| `NELM` | `60` | 单个离子步内**电子自洽的最大步数** |
| `NELMIN` | `2` | 电子自洽的**最小**步数；**做 MD / 离子弛豫时用 `4~8`** |
| `NSW` | `0` | 离子步最大步数 |
| `NPAR` | — | **建议 `NPAR ≈ √核数` 或 `NPAR ≈ 每个节点的核数`**（另一套经验，见 `performance.md` §四） |
| `SYMPREC` | `1e-5` | 对称性判断的精度；结构畸变小时可放宽（如 `1e-4`/`1e-3`）让程序识别出更高对称性 |
| `ICHARG=4` | — | **从 `POT` 文件读取电荷密度**（该档位平时少用，知道有这一档即可） |
| `ICHARG=11` | — | **从旧 `CHGCAR` 读入电荷密度**，做能带划分/本征值与 DOS 的非自洽；**密度保持不变** |
| `ICHARG=12` | — | **MD 过程中的非自洽计算**用 |

### 二附4、偶极修正与极化（`LCALCPOL` / `DIPOL` / `IDIPOL` / `LDIPOL`）

| 参数 | 说明 |
| --- | --- |
| `LCALCPOL` | `.TRUE.` 时用 **Berry phase** 计算**电子极化**，结果写在 `OUTCAR` 的 `Total electronic dipole moment` 一行 |
| `DIPOL` | 偶极修正的**参考点**（分数坐标，如 `0.2 0.2 0.2`）；**不要设在原子上或迁移路径上**，放在真空层一侧或质心 |
| `IDIPOL` | 在哪个方向做偶极修正：`1/2/3` = x/y/z（**二维/表面体系用真空方向的 `3`**），`4` = 全部方向 |
| `LDIPOL` | ⚠️ **不要设 `.TRUE.`**：它会默认取 `IDIPOL=4`，让 VASP 按"偶极中心"自行加一个任意方向的偶极修正，**等价于在周期方向上加任意电场**（易出问题、收敛慢）；**请显式给 `DIPOL` + `IDIPOL`** |

完整流程（FE 相 − NP 相、参考相非半导体的处理、L-G 系数与 `Tc`）见 `workflows.md` 第三十一节。

### 二附5、自旋轨道耦合（SOC：`LSORBIT` / `LNONCOLLINEAR` / `SAXIS` / `GGA_COMPAT`）

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `LSORBIT` | `.FALSE.` | 打开 **SOC**，**并自动设置 `LNONCOLLINEAR=.TRUE.`**；⚠️ **只对 PAW 赝势有效**（超软赝势无效） |
| `LNONCOLLINEAR` | `.FALSE.` | 非共线磁性（`MAGMOM` 每原子给 3 个分量）；**可以只做非共线而不做 SOC** |
| `SAXIS` | `(0⁺, 0, 1)` | 全局自旋量子化轴；**`MAGMOM`、`OUTCAR`/`PROCAR` 的磁化、`WAVECAR`、`CHGCAR` 的磁化密度都以此轴为基准** |
| `GGA_COMPAT` | `.TRUE.` | **非共线计算建议设 `.FALSE.`**（提高 GGA 数值精度，手册自 VASP 4.6 起建议） |
| `LMAXMIX` | `2` | SOC/`+U`/`ICHARG=11` 时按元素设：**d → `4`、f → `6`**（做 MAE 时要在**共线那一步**就设好） |
| `NBANDS` | 自动 | **SOC 下能带数要翻倍**（自旋分量数从 1 变 2） |
| `ISYM` | `2` | ⚠️ **SOC 计算建议 `ISYM = -1`（完全关对称性）**：k 点集会随自旋方向变化，k 点数一变 `WAVECAR` 就无法正确重读 |
| `LORBMOM` | `.FALSE.` | `.TRUE.` 时**输出轨道磁矩**（研究 MAE 的轨道贡献、或需要 `L` 的信息时打开） |

完整流程（MAE 的共线 → 非自洽比较、`E_soc` 验证）见 `workflows.md` 第三十三节。

### 二附6、电子迭代算法与混合（`ALGO` / `TIME` / `WEIMIN` / `NSIM` / `IMIX` / `WC`）

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `ALGO` | `Normal` | 电子最小化算法：**`Normal`(=`IALGO=38`，最稳)**、`Very_Fast`(`48`)、**`Fast`(38→48，可靠且快)**、`Damped`(`53`，面向金属/小带隙，配 `LDIAG`)、`All`(`58`，面向绝缘体)。详见 `errors.md` §2.1 |
| `TIME` | `0.4` | `Damped`/`All` 的试验步长；**太小收敛慢、太大会发散**——**从小的值开始、每次 ×1.2 测到发散，取"仍稳定收敛的最大值"** |
| `WEIMIN` | 自动 | 未占据带的优化阈值；**`Very_Fast` 在 MD/弛豫中若报未占据带问题，设 `WEIMIN = 0`** |
| `NSIM` | `4` | 每个 band 同时优化的数目；**`ALGO=Normal` 出问题时先试降低它** |
| `IMIX` | `4` | 混合方式：`4` = `WC>0` 时 Pulay's scheme（默认）、`WC=0` 时 Broyden 2nd；`1` = Kerker（**HSE06 + `ALGO=Normal` 时论坛建议用 `1`**） |
| `WC` | `>0` | 只影响 `IMIX=4` 的分支选择；**不建议修改** |
| `LDIAG` | `.TRUE.` | 子空间对角化；`Damped` 配 `.TRUE.` 求金属/小带隙基态更稳，设 `.FALSE.` 收敛快但**可靠性显著下降** |

磁性体系的混合实战（线性混合、`AMIX` 量级、默认 `0.4` 过大的坑、`AMIX` 扫描 vs 手册公式）
见 `errors.md` §2.1 与 §2.6。

### 二附7、约束磁矩（`I_CONSTRAINED_M` / `M_CONSTR` / `LAMBDA` / `RWIGS`）

| 参数 | 说明 |
| --- | --- |
| `I_CONSTRAINED_M` | `1` = 只约束**方向**；`2` = 约束**大小 + 方向**；`4` = 约束**方向 + 符号**（⚠️ 需 **VASP ≥ 6.4.0**）。⚠️ `=1` 分不清同一直线上的正反向 |
| `M_CONSTR` | **目标磁矩**，格式与 `MAGMOM` 相同（非共线时每离子 3 个数）；**经验上要与 `MAGMOM` 写成完全一致** |
| `LAMBDA` | 约束的**能量惩罚系数**；需**从小到大扫描**，直到惩罚项 `E_p` 很小且磁矩方向正确（过高会出错） |
| `RWIGS` | 投影的 Wigner-Seitz 半径（Å）；**`grep -e RWIGS POTCAR` 可直接取用**（该行两个值分别是 a.u. 与 Å），也需要收敛测试 |

⚠️ 用这套参数时**总能必须减掉 `E_p`**（`OSZICAR` 末尾读取），否则能量差会系统性偏差；
完整流程见 `workflows.md` 第三十四节，陷阱另见 `errors.md` §七。

### 二附8、光学性质（`LOPTICS` 等）

| 参数 | 说明 |
| --- | --- |
| `LOPTICS` | `.TRUE.` 时计算**频率相关介电矩阵**（`OUTCAR` 里给出实部/虚部，六列 `X Y Z XY YZ ZX`）。⚠️ 前提是**独立粒子 + 无局域场效应** |
| `NBANDS` | 默认值 **`max(NELECT/2 + NIONS/2, NELECT×0.6)`**；**最小要求：所有占据态 + 一个空带**；**光学计算取普通计算（自洽步）的 `2~3` 倍**（`grep NBANDS OUTCAR` 拿默认值），它决定可覆盖的最高跃迁能 |
| `CSHIFT` | 复数位移（小量 η），控制谱线**展宽/平滑**；**默认：线性响应 `0.1`、GW 计算 `OMEGAMAX×1.3/max(NOMEGA,40)`**——所以 `CSHIFT=0.1` 不是经验值而是默认值 |
| `NEDOS` | 光学计算里它控制**频率网格密度**（示例 `2000`），与 DOS 里的同名参数用途不同 |
| `ALGO` | 光学官方推荐 **`Exact`**，但**实测代价极高（「几乎算不动」）**——常用 `Normal` 起步、逐步提高 |
| `NPAR` | 光学计算常**调小**（示例从 `4` 改成 `1`），另有 `ISYM = 0`、`ISIF = 2`、`NSW = 0` 等静态设置 |

## 三、离子步（Ionic Relaxation）

| 参数 | 常用取值 | 含义与经验 |
| --- | --- | --- |
| `NSW` | `0`（默认，离子不动）/ 优化 `100`~ | 离子运动的最大步数 |
| `IBRION` | `-1`/`0`/`1`/`2`/`3`/`5`/`6`/`7`/`8`/**`44`** | 见下方 §三附；速记：`-1` 离子不动 / `0` MD / `1` 准牛顿(RMM-DIIS) / `2` **共轭梯度** / `3` 阻尼 MD / `5`、`6` 有限差分力常数（`6` 用对称性）/ `7`、`8` DFPT 力常数（`8` 用对称性）/ **`44` 改进的二聚体方法（找鞍点、过渡态）**。配合 **`NFREE`**（位移次数：`1` 单侧、`2` 正负各一、`4` 四次）与 **`POTIM`**（位移距离） |
| `ISIF` | 常用 `2` / `3` | 应力张量与自由度：`0` 不算应力；`1` 只算总应力、**只优化离子**（不改胞）；`2` 只优化离子；`3` **同时优化离子+胞形状+体积**；`4` 优化离子+胞形状（**体积不变**）；`5` 只改胞形状；`6` 优化胞形状+体积（不动离子）；`7` 只优化胞体积。**变体积的计算需要提高截断能** |
| `EDIFFG` | **负值**如 `-0.02`（声子建议 `-0.001` 或更小） | 收敛判据：**正值 = 能量判据**（两次离子步总能差）；**负值 = 力判据**（所有离子受力小于其绝对值）。默认是 `EDIFF×10` 的正值，**建议总用负值**。符号陷阱见 `errors.md` §3.1 |
| `ISYM` | `1`/`2`/`3` 开；`-1`/`0` 关 | 对称性开关；PAW 计算默认 `ISYM=2`；`SYMPREC` 决定找对称性的精度（相关报错见 `errors.md` §8.2） |
| `MAGMOM` | 逐原子给 | 初始磁矩。⚠️ **加 U 与加磁矩一样，必须在 opt 阶段就加、且全程保留** |
| `POTIM` | MD：时间步长（fs）；优化：力的缩放因子（默认 `0.5`）；`IBRION=5/6`：位移步长（Å） | 简单理解为"控制原子一次移动多远"。**结构极不合理时可先粗优化、适当增大**；**若多次弛豫仍在极小值附近振荡不收敛，则调小并配 `IBRION=1`**。EDDRMM 类发散的 `POTIM` 阶梯见 `errors.md` §2.6 |
| `TEBEG` / `TEEND` | 如 `300` | MD 的初始/终了温度（AIMD 流程见 `workflows.md` §二十六） |

### 三附、`IBRION` 怎么选 + `POTIM` 的实测技巧（官方语义）

**选择指南**（译自 VASP Wiki 的 `IBRION` 页）：

- **复杂弛豫问题优先 `IBRION=2`（共轭梯度）**——官方原话：它拥有**最可靠的备份路径**；
- **初始结构猜得很糟**时，**阻尼分子动力学 `IBRION=3`** 很有用；
- **已经很接近局部极小值**时，**`IBRION=1`（RMM-DIIS）通常最好**；
- `IBRION=5`/`6` 用**有限差分**求二阶导（Hessian、声子频率）；`IBRION=7`/`8` 用 **DFPT**；
- **`IBRION=44`：改进的二聚体方法（improved dimer method）**——用于**找鞍点/过渡态**（不必像 NEB 那样先有一条反应路径）。
  官方页：<https://www.vasp.at/wiki/index.php/Improved_Dimer_Method>。

**关于 DFPT（`7`/`8`）的现实评价**（官方说得很直白，值得记住）：

- VASP 的线性响应实现**只支持与超胞对称性相同的位移**，即**只能算超胞在 Γ 点的声子频率**；
- 因此与有限差分（5/6）相比**几乎没有优势**；线性响应**仅限 LDA 与 GGA**；
- **不能给出弹性张量**（还没实现相对应变张量的线性响应）；
- 它**唯一的优点是不必挑有限位移的大小** → 官方建议：**先用线性响应算声子频率，再用有限差分法确定合适的位移量**，
  两者精度相当。
- 若 INCAR 里设了 **`LEPSILON=.TRUE.`**，会一并得到**波恩有效电荷、压电常数与离子对介电张量的贡献**
  （见 `workflows.md` §二十三）。

**`POTIM` 的正确理解与"最佳值"的实测方法**：

- **所有弛豫算法都要给 `POTIM`**；对 `IBRION>0`，力在内部被缩放，所以 **`POTIM` 没有物理意义、只是个缩放因子**；
- **很多体系的最佳 `POTIM` 在 `0.5` 左右**；**准牛顿（1）与阻尼（3）对 `POTIM` 敏感**——
  **不确定就选 `IBRION=2`**（CG 对 `POTIM` 最不挑）；
- 💡 **`OUTCAR` 会告诉你最佳 `POTIM`**：用 `IBRION=2` 时每个校正步后会打印

```
trial: gam= .00000   g(F)= .152E+01   g(S)= .000E+00   ort = .000E+00
(trialstep = .82)
```

  - `gam` 上一步的共轭参数；`g(F)`/`g(S)` 是**力**与**应力张量**的模长；
    `ort` 指示当前搜索方向与上一方向的正交性（**最佳步长时它应远小于 `g(F)+g(S)`**）；
  - `trialstep` 是当前试验步的步长，它等于上一步中实现线最小化的平均步长 →
    **把当前 `POTIM` 乘以 `trialstep`，就是（这一步的）最佳 `POTIM`**。
- **`ISIF` 的作用范围**：`IBRION=1/2/3` 时由 `ISIF` 决定**晶胞形状与离子位置是否改变**；
  而**分子动力学（`IBRION=0`）只有在使用 Tomáš Bučko 的动力学模块时才允许晶胞形状变化**
  （这与 `workflows.md` §二十六 的 NVT/NPT 讨论呼应）。

### 二附2、DFT+U（Hubbard U）参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `LDAU` | `.FALSE.` | 是否启用 DFT+U |
| `LDAUTYPE` | **`2`** | `1` Liechtenstein；**`2` Dudarev 简化（旋转不变，常规 +U 计算用它）**；`4` 同 `1` 但无交换分裂。⭐ 另有 **`3`：专用于「线性响应求 `U`」**（只算占据矩阵的响应，不加 U 势；⚠️ **常规参数表里不列它**，见 `workflows.md` 第三十九节） |
| `LMAXMIX` | `2` | **必须大于所加轨道角量子数：d → `4`，f → `6`** |
| `LDAUL` | `NTYP*2` | **每个元素一个值**：`-1` 不加 / `1` p / `2` d / `3` f |
| `LDAUU` | `NTYP*0.0` | 每个元素的 **U（eV）** |
| `LDAUJ` | `NTYP*0.0` | 每个元素的 **J（eV）** |
| `LDAUPRINT` | `0` | `1`/`2` 时**输出更详细的 +U 信息**（排查 `+U` 相关问题时很有用） |
