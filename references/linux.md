# Linux 常用命令速查（面向 VASP 操作）

> 用途：跑 VASP 的日常操作——**看输出、批量造目录、就地改参数、递归查找**——都靠这几条命令。
> 细节用法随时 `man <命令>`。主要来源：知乎《VASP学习记录(三)：VASP中常用的Linux命令》
> （`articles/20261001-VASP学习记录_三_VASP中常用的Linux命令.md`）。

## 一、文件与目录

| 命令 | 作用 |
| --- | --- |
| `cat xxx` | 在终端输出整个文件 |
| `cat -n xxx` | 同上，**带行号** |
| `grep A xxx` | 在 xxx 里查找含 `A` 的行 |
| `ls` | 列出当前目录内容 |
| `ls *` | **连同子目录的内容一起展开**（`*` 由 shell 展开） |
| `cd xxx` | 进入目录 |
| `mkdir xxx` | 新建目录 |
| `cp xxx yyy` / `cp -r xxx yyy` | 复制文件 / **复制目录**（`-r` 递归） |
| `rm xxx` / `rm -r xxx` | 删除文件 / **删除目录** |
| `mv A xxx` | 移动（文件或目录），也可用来改名 |

## 二、批量操作（VASP 里最常用）

### 2.1 `for` 循环

```bash
for i in {2..9}; do cp -r 0.01 0.0$i; done      # 把 0.01 复制成 0.02 … 0.09
```

- `{a..b}` **只支持整数、间隔固定为 1**；`$i` 是循环变量（占位符）。
- 想要**小数间隔或任意取值**就用 `seq`：

```bash
for i in $(seq 0.02 0.01 0.05); do cp -r 0.01 $i; done   # i = 0.02 0.03 0.04 0.05
```

- **变量与 `{}`**：只有一个变量时可以写 `$i`；**要拼接字符或多个变量时必须加花括号**：

```bash
for i in {1..9}; do cp -r 0.01 ${i}${i}${i}; done        # 命名成 111 222 333 …
```

> 这套写法正是**批量造应变/参数序列**的基础（参见 `workflows.md` 第十六节迁移率的 `mobility.sh`、
> 第十三节 idealdeform 的应变目录）。

### 2.2 `sed -i` 就地改参数

```bash
sed -i '3s/0.01/0.02/g' INCAR      # 把 INCAR 第 3 行的 0.01 全部替换成 0.02
sed -i '3,5s/0.01/0.02/g' INCAR    # 第 3~5 行
```

- `-i` = **直接改源文件**（不加只打印到屏幕）；
- `3s` = 第 3 行；`3,5s` = 3 到 5 行；`g` = 该行内**全局**替换（不写只替换每行第一处）。

## 三、通配符、引号与逻辑

- **`*` 通配符**：`grep SIGMA xxx/*/INCAR` —— 一次在所有子目录的 `INCAR` 里找 `SIGMA`。
- **单双引号的区别**：
  - `'...'`（单引号）**不解析变量**，所见即所得；
  - `"..."`（双引号）**会解析变量**。
  → 想在字符串里用变量，就把外层换成双引号。
- **`&&` 与 `||`**：
  - `命令1 && 命令2`：从左到右执行，**一旦某条失败就停下**；
  - `命令1 || 命令2`：从左到右执行，**一旦某条成功就停下**。
- **反选**（保留一部分、删掉其余）：

```bash
rm -r !(1|2)      # 删除除 1 和 2 之外的所有目录
```

  - ⚠️ `!(...)` 属于 **extglob** 语法，**bash 里默认没开**——先执行 `shopt -s extglob` 再用，
    否则会报语法错误（原文未提这个前提）。
  - 更保险、更易读的替代写法：`mkdir keep && mv 1 2 keep/`（把要留的先搬走）。

## 四、⚠️ 破坏性命令的安全习惯

`rm -r *`、`rm -r !(1|2)` 这类命令**没有回收站**，且一旦路径写错就不可逆：

1. **先 `ls` 看清楚**（或把 `rm` 换成 `ls` 预览一遍要删的东西）；
2. 用 `rm -r ./目标目录` 这种**带相对前缀**的写法，别在 `~` 或 `/` 下裸跑；
3. 重要结果先 `cp -r` 备份一份，或干脆移动而不是删除。

## 六、Vim 速查（改 INCAR / POSCAR / KPOINTS 都靠它）

### 6.1 三种模式

- **正常模式**：打开文件后就是它——用快捷键移动/删除/复制，按 `:` 进入命令行（`:wq`、`:q!`…）。
- **插入模式**：在正常模式按 **`i`**（光标前插入）、**`a`**（光标后）、**`o`**（下一行新开一行）。
- **可视模式**：`v` 字符可视、`V` 整行可视、**`Ctrl+v` 块（列）可视**。
- 任何模式下按 **`Esc`** 回到正常模式。

### 6.2 最小可用流程

```bash
vim INCAR      # 打开（文件不存在则新建）
#   i  → 编辑 → Esc → :wq 保存退出（或 :q! 不保存退出）
```

### 6.3 移动（正常模式）

| 按键 | 作用 |
| --- | --- |
| 方向键 | 光标上/下/左/右 |
| `w` | 前移一个单词，停在**下一个单词开头** |
| `b` | 后移一个单词，停在**上一个单词开头** |
| `fc` | 移到本行**下一个字符 `c`** 处 |
| `nG` | 跳到第 **n** 行（`gg` 到文件头、`G` 到文件尾） |
| `Ctrl+f` / `Ctrl+b` | 下翻 / 上翻**一整屏** |
| `Ctrl+d` / `Ctrl+u` | 下翻 / 上翻**半屏** |
| `Ctrl+e` / `Ctrl+y` | 向下 / 向上滚动**一行** |

### 6.4 查找、替换与撤消

| 命令 | 作用 |
| --- | --- |
| `/something` | 向后查找 `something`（按 `n` 跳到下一处、`N` 上一处） |
| `:n1,n2s/old/new/g` | 把 **n1~n2 行**的 `old` 全部替换成 `new`（原文用法） |
| `:%s/old/new/g` | **全文**替换（常用补充） |
| `U` | **取消当前行的所有改动**（原文用法） |
| `u` / `Ctrl+r` | 撤消上一步 / 重做（常用补充） |

### 6.5 VASP 场景里怎么用

- **改一个参数**：`/ENCUT` 定位 → `i` 改数字 → `Esc` → `:wq`；
- **全文换一个值**：`:%s/ISMEAR = 0/ISMEAR = 1/g`；
- **改整列坐标**（进阶）：`Ctrl+v` 纵向选中一列 → `I` 在**每行的同一位置**插入 → `Esc` 生效；
- ⚠️ **批量改参数优先用 `sed -i`**（见第二节）：Vim 适合交互式修一处，跨目录批量改还是脚本更稳。

## 七、awk 速查（从 VASP 输出里抠数据）

### 7.1 通用形式

```bash
awk [-F 分隔符] [-v 变量=值] 'BEGIN{ 初始化 } { 逐行处理 } END{ 收尾 }' file1 file2 ...
```

- **五部分都可以省略**（分隔符、变量、BEGIN、主体、END），文件可以给一个或多个；
- 执行顺序：**BEGIN 在读取数据之前跑一次** → **主体对每一行跑一次** → **END 在读完所有数据后跑一次**；
- 主体部分可以理解成"**省略了对行做 for 循环的写法**"；`$1`、`$2`… 是**按分隔符切出的第 1、2… 列**，`$0` 是整行。

一个完整例子（成绩表求和，最后 `column -t` 只是对齐输出）：

```bash
awk 'BEGIN{print "姓名 语文 数学 英语 总成绩"; sum1=0; sum2=0; sum3=0; sumall=0}
     {print $1,$2,$3,$4,$2+$3+$4; sum1+=$2; sum2+=$3; sum3+=$4; sumall+=$2+$3+$4}
     END{print "合计",sum1,sum2,sum3,sumall}' grade | column -t
```

### 7.2 分隔符与内置变量

- **指定分隔符**：`-F`。例：`echo '192.168.1.1' | awk -F "." '{print $2}'` → `168`；
  用默认（空格/TAB）切这个串就没有输出。

| 变量 | 含义 |
| --- | --- |
| `NF` | 当前行**被切分后的字段数** |
| `NR` | awk **已读的总行数** |
| `FNR` | **当前文件的**记录数（换到第二个文件会从 0 重新开始，而 `NR` 继续累加） |
| `RS` | 输入记录的**行分隔符**（默认换行） |
| `FS` | **字段分隔符**（默认空格/TAB） |

### 7.3 常用小技巧

- **求和 / 平均**（VASP 里提取一系列能量求平均是同类操作）：

```bash
awk 'BEGIN{sum=0} {sum+=$1} END{average=sum/NR; print "sum="sum, "average="average}' data
```

- **三元运算符** `表达式 ? 动作1 : 动作2`：

```bash
awk 'BEGIN{a=2; print a==1?"ok":"no ok"}'      # 输出 no ok
```

- **只对匹配的行动手**：`awk '/E0/{print $5}' OSZICAR`（等价于先 `grep` 再 `awk`）。
  ⚠️ 列号随 VASP 版本与输出行格式略有差别，**先用 `head` 看一眼那一行长什么样**再定 `$n`。

### 7.4 VASP 场景（和第五节配合看）

| 想干什么 | 命令 |
| --- | --- |
| 取 MD/弛豫每一步的能量（画时间序列） | `grep "free energy" OUTCAR \| awk '{print $5}' > energy.dat` |
| 取弹性矩阵那 6 行 | `grep -A 8 "TOTAL ELASTIC" OUTCAR \| tail -6 > ecs.dat` |
| 从任意表格里取第 k 列 | `awk '{print $k}' file` |
| 求和/平均（如若干步的平均能量） | `awk '{s+=$1} END{print s/NR}' file` |
| 输出对齐好看点 | `... \| column -t` |

> ⚠️ 用 `awk` 是为了"临时看数、快速取列"；**要做正经分析/画图，用 `workflows.md` 第二十节的 Python 路线**
> （pandas 或 numpy+matplotlib），可复现性更好。
