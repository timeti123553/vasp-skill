# POTCAR 使用与选势指南（官方推荐）

> 用途：**选哪个赝势文件**、组装 POTCAR 的规矩、以及按元素分区/按计算类型的官方建议。
> 入门概念（`PBE`/`PAW`/`PW` 三者关系）见 `references/onboarding.md` §3；报错处理见 `errors.md` §1.4。
> 本页主要译自 VASP Wiki 的 [`POTCAR`](https://www.vasp.at/wiki/index.php/POTCAR) 与
> [`Available PAW potentials`](https://www.vasp.at/wiki/index.php/Available_PAW_potentials)
> （经 June976 的博客整理：`articles/20261001-VASP中POTCAR使用指南.md`）。

## 一、组装与使用规矩

- **多元素要把各自的 POTCAR 按 POSCAR 的元素顺序连起来**：

```bash
cat ~/pot/Al/POTCAR ~/pot/C/POTCAR ~/pot/H/POTCAR > POTCAR   # 第一个对应 POSCAR 第一个元素
```

- ⚠️ **顺序不一致时，VASP 会按赝势文件里的顺序去识别元素 → 结果错误**（不是报错，是错结果）。
- ⚠️ **POTCAR 是只读文件**：**不要修改它**，尤其**绝对不要动 `LEXCH` 标签**——它用于"用 INCAR 指定的泛函
  重新计算 PAW 球内交换关联能"的原子校正；改了 VASP 就不能正常工作。
- VASP 3.2+ 的 POTCAR 内含每个元素的**质量 `POMASS`**、**价电子数 `ZVAL`**、参考构型能量、以及
  **默认截断能 `ENMAX`/`ENMIN`**：
  - 若在 INCAR 里重新指定了质量或价电子数，VASP 会**拿 POTCAR 里的值来核对并可能报错**；
  - **`ENCUT` 在 INCAR 里不是必须的**（POTCAR 自带默认值）；**INCAR 的值会覆盖默认值**；
    **多元素时取最大的那个 `ENCUT`**。

## 二、后缀怎么读（官方定义）

| 后缀 | 含义 |
| --- | --- |
| `_h` | 比标准势**更硬**，需要**更大的截断能** |
| `_s` | 比标准势**更软** |
| `_pv` | **半芯态 p 电子**当价电子 |
| `_sv` | **半芯态 s 电子和 p 电子（如果有）**当价电子 |
| `_d` | **半芯态 d 电子**当价电子 |
| `_2` / `_3` | 特殊 GGA 势（部分 f 冻在芯中），`n` 表示**形式化合价**（见 §四 f 区） |

- **价电子构型怎么读**：看 POTCAR 里的 **`ZVAL`** 与 **`Atomic configuration` 表格**——表里**先列芯电子态、
  再列价电子态**，**占据态的最后一行相加正好等于 `ZVAL`**。
  ⚠️ 注意两点：该构型**可能与真空中的基态构型不同**；**这些行不按能量排序**
  （例：Gd 的强定域 3f 电子能量更高，却仍被当作芯电子）。

## 三、按元素分区的官方建议

**第一行元素（B–F 等）**

- 标准 PAW 势适合**大多数目标**；**325–400 eV** 可靠；**要预测振动性质需要 370–400 eV**；
  结构和能量差异在 **325 eV** 就能很好重现；第一行二聚体（N₂、CO、O₂）**键长典型误差约 1%**。
- **`_h` 硬势**的结果与目前最好的一类 DFT 计算（FLAPW、超大基组高斯）**基本相同**。
- **软势在 250–280 eV** 使用：对**多数氧化物**（VxOy、TiO₂、CeO₂）可靠，
  但**描述沸石的某些结构细节（晶胞参数、体积）会失败**。

**碱金属 / 碱土金属**

- **Li、Be 应使用 `_sv`**（比标准势**可移植性更好**）。
- 其它碱/碱土也应收半芯 s、p 入价态：**Na–Ca 把 2p/3p 当价态通常还不够**；
  **Rb–Sr 需 4s、4p、5s、5p 全当价电子（`_sv`）**。
- ⚠️ **与普遍看法相反**：这些元素**与强电负性元素（如 F）结合时非常难赝化，误差可能比平时更大**。

**d 区元素**

- 半芯 p、s 同样**宜当价态**；**多数情况下冻住半芯态也能得到可靠结果**。
- **经验判据：当 p 态本征能量 ε 高于 3 Ry 时，就应当把它当价态处理。**
- **早期过渡金属用 `_pv`**；**后期过渡金属可以冻住半芯 p**（贵金属尤甚）；
  **4d 元素问题最大——建议一直到 Tc 都用 `_pv`**；5p 元素（Hf 起）可用标准势，但**建议先测试**；
  有些元素也可用 `_sv`（`Nb_sv`、`Mo_sv`、`Hf_sv`），截断能与 `_pv` 相近。
- **做 HF/杂化泛函时，强烈建议尽量用 `_sv` 或 `_pv`。**

**p 区元素（含第一行）**

- **Ga、Ge、In、Sn、Tl–At：d 态应视为价态（用 `_d` 势）**；把 d 当芯的势也能用，但**要特别小心**。

**f 区元素**

- **DFT 本身难以处理 f 电子**：部分填充的 f 态会被固定在费米能级，导致 **Pr–Eu 与 Tb–Yb 之间过度束缚**，
  **在 f 电子 1/4 或 3/4 填充时误差最大**（Gd 处理得好，因为 7 个电子基本填满 f 壳层）。
  **这是 DFT 的固有局限，不是 VASP 的问题。**
- **常规处理办法：把 4f 电子放进芯电子**（相应势可用，但**描述 f 轨道磁性会失败**）；
  把 f 当价态的 PAW 势也可用，但 f 定域时**描述电子性质会失败**——此时需要更小心处理相关效应，
  **例如用杂化泛函或加 U**。
- **更软的版本**要当心：半芯 p 常被当价电子、半芯 s 只在标准势里当价态；
  **多数应用（氧化物、硫化物）应用标准版**，因为更软的版本可能在**费米能级附近产生 s 幽灵态**（如 `Ce_s`）；
  **金属间化合物**用更软的势可达到足够精度。
- **Ce–Lu 另有专门 GGA 势**（部分 f 冻在芯中）：**芯中电子数 = 总价电子数 − 形式化合价**。
  例：Sm 共 8 个价电子（6 f + 2 s），多数计算取 3 价 → 5 个 f 进芯 → 用 `Sm_3`；
  **`_n` 的 n 可为 2 或 3**（如 `Ce_3` 是三价 Ce；**四价 Ce 用标准势**）。

## 四、按计算类型的建议

- **PBE/常规 DFT**：用标准 PAW 势；**含短键二聚体的化合物（O₂、CO、N₂、F₂、P₂、S₂、Cl₂）建议用 `_h` 势**
  （`C_h`、`O_h`、`N_h`、`F_h`、`P_h`、`S_h`、`Cl_h`）。
- **GW / RPA / 激发态 / 显式相关波函数（MP2、耦合簇）**：用 **GW 势**——它与上述 DFT 结果**几乎相同**
  （不会让 DFT 计算变差），而且在**全电子计算中比 DFT 势更优**；
  在**远高于费米能级的高能区（比真空能级高 10–20 Ry）有更好的散射特性**；含短键二聚体同样建议 `_h`。
  - `C_GW_new`/`N_GW_new`/`O_GW_new`/`F_GW_new` 用 **f 赝势作局部势 + 带 d 投影**；
    而 `C_GW`/`N_GW`/`O_GW`/`F_GW` 用 **d 赝势作局部势、不含 d 投影**；
  - **以 `ENMAX` 为截断能时，`_GW`（旧）通常收敛更快**；新势是否更准"还没有完全搞清楚"，
    实践中提升不明显，**通常不足以证明更大的计算负载是合理的**。
- **HF / 杂化泛函**：**严格建议使用标准、标准 GW 或硬势**；⚠️ 例：过渡金属氧化物里用 **`O_s` 可能造成
  不可接受的巨大误差**。一般规律：**软势不太可能从一个交换关联泛函迁移到另一个**，
  **需要精确交换时常失败**。

## 五、版本与其它细节

- **强烈建议使用官网 5.4 版 POTCAR**（每个文件有唯一 SHA 哈希）；**5.2 版也很流行（Materials Project 在用）**；
  两者差别很小、只涉及少量元素。
- **5.4 版的变化**：`W_sv` 取代 `W_pv`；**`At_d` 不再提供**（该势会导致晶格参数出现很大错误）。
- **类氢势**：提供价电子数 0.25~1.75 的版本；⚠️ **POTCAR 限制价电子数的位数**（有些 2 位、多数 3 位）——
  **用三个 `H.33` 不会得到 0.99 或 1.0 个价电子**，可能产生**无法预料的电子-空穴态**；
  解决办法是**微调 INCAR 里的 `NELECT`**。
- **US-PP 原则上仍可用但不鼓励**：对 C、N、O 而言截断能并没有明显减小、基组增加也很少，
  所以**用 PAW 算含这些元素的化合物并不比 US-PP 更贵**。
- PAW 比 US-PP 更精确的两个原因：**芯半径更小**；**重构了芯区所有节点的精确波函数**（代价是更大的基组/截断能）。
