# 入门地图（写给做实验、要开始做计算的人）

> 本文件面向**第一次接触第一性原理计算**的人：先把"计算到底在干什么"讲清楚，再把你领到手边能用的文档。
> 操作细节、参数、报错处理不在这里——按第四节的导航去对应文件查。
> 主要来源：知乎《材料科学实验人员 如何入门 第一性原理计算（计算材料学/VASP）（从0到上手）》
> （`articles/20261001-材料科学实验人员_如何入门_第一性原理计算_计算材料学_VASP_从0到上手.md`）。

## 一、计算和做实验是同一件事

| 实验 | 计算 |
| --- | --- |
| 原料：药品 | **原子**（往晶胞里"丢"原子；O₂ 就是丢 2 个 O） |
| 锅炉：坩埚 | **晶胞**（重复单元；晶胞够大时，可认为与邻胞的相互作用可忽略） |
| 烧结 | **结构优化**（初始位置随意，优化后收敛到最稳定排布） |
| 测 XRD | 算 XRD（软件一步生成，如 VESTA） |

- **结构优化在做什么**：原子间吸引力 > 排斥力就靠近一步，反之远离一步，且步长逐步减小，直到"力小于某个界限"（判据远小于 1 N 那种量级）就认为稳定了。
  → 判据就是 `EDIFFG`，见 `workflows.md` 第一节。
- 优化完能得到：键长、电荷分布、晶格参数；再进一步：化合价、成键方式、能带、带隙……
- **力是怎么来的**：涉及势场与电荷分布，是第一性原理理论的内容（想看就翻凝聚态/密度泛函的书；不想看，把它当成"高级的牛顿力学"当工具用也行）。

## 二、在哪儿算、能不能发表

- **三种运行环境**：**机群**（自己装编译 Linux，最麻烦）、**超算**（通常已装好 VASP，只管用）、
  **云计算平台**（浏览器 + Windows 界面，最省事，如 MatCloud+，见 `references/tools.md` 六）。
  超算与云的底层一样，区别只是你看到的界面是 Linux 终端还是浏览器。
- ⚠️ **授权**：**VASP 不是免费软件**。装机试玩可以，但**未购买授权得到的结果不能发表**——
  投稿前务必确认课题组/单位的许可状态。
- 结果可视化常用 **VESTA**（免费，官网可下载；原文另给了网盘副本，这里不再转抄）。

## 三、四个输入文件与"起步八个参数"

四个文件回答三个问题——**算什么（POSCAR/POTCAR）、怎么算（INCAR）、在哪些 k 点算（KPOINTS）**：

| 文件 | 一句话 |
| --- | --- |
| `POSCAR` | 结构（位置）：第 1 行备注（随意）→ 第 2 行缩放系数（写 1.0）→ 3–5 行晶胞 → 第 6 行元素 → 第 7 行各元素原子数 → 第 8 行 `Direct` → 坐标行 |
| `POTCAR` | 赝势/价电子；**必须与 POSCAR 的元素顺序一致**（见 `errors.md` §1.4） |
| `KPOINTS` | k 点网格；自洽用 `Automatic`，能带用 `Line-mode` |
| `INCAR` | 计算参数（精度、步数…） |

**INCAR 起步参数**（原文给新手的八个，够跑通简单体系）：

- `IBRION=2`：原子移动算法（CG）；做 MD 要换别的值。
- `ENCUT`：截断能，越大越准越慢。原文说"**一般 520 eV 满足绝大多数体系**"——这是个常见起点，
  但**更稳的做法是看赝势**：先 `grep ENMAX POTCAR`，取 `ENCUT ≥ max(ENMAX) × 1.2–1.3`（见 `errors.md` §1.4）。
- `EDIFF=1E-5`（原文写 `0.1E-04`）：相邻两步能量差小于它就算能量收敛。
- `EDIFFG`：收敛判据。⚠️ **符号很关键**：**负值才是力的判据**（如 `-0.02`），
  **正值会被当成能量判据**——原文把它写成 `0.02 eV/Å` 并称作"力的收敛标准"是**笔误**，
  照抄会让"收敛"变得毫无意义。详见 `errors.md` §3.1。
- 还有 `ISPIN`/`ISTART`/`ISYM`/`ISMEAR` 等，跑通简单体系后再逐个了解。

### 3.1 顺带澄清：`PBE` / `PAW` / `PW` 三个「P」别混

| 名称 | 是什么 | 常见替代 |
| --- | --- | --- |
| `PBE` | **泛函**（交换关联） | `LDA`、`PW91`、`HSE`（杂化）、`SCAN`… |
| `PAW` | **「赝势」的角色**——简化内层电子、加快计算 | `USPP`（超软赝势）、`NC`（模守恒） |
| `PW` | **基组**（平面波） | 原子轨道基（分子体系软件常用） |

- 三者**互相独立**，我们平常算的是组合**【PBE, PAW, PW】**；换泛函、换赝势、换基组是三个独立的决定（例如算带隙把 PBE 换成 HSE，早年常用 USPP 而非 PAW）。
- ⚠️ 严格讲 **PAW 不是一种赝势方法**：它扮演的角色（简化内层电子）与赝势相同，但**与赝势是并列关系**；
  `POTCAR` 里装的就是 PAW 的那套数据。
- **`POTCAR` 里到底存了什么**：平面波基组没法表示核附近剧烈振荡的「真原子轨道」，PAW 的做法是**在核附近某个半径内用很密的点把波函数直接记下来**——这就是 `POTCAR` 后半部分的 **`ae wavefunction` / `pseudo wavefunction`**（用文本编辑器打开就能看到），也解释了它为什么动辄上千行。
- **精度从哪来**：PAW 的误差主要来自**展开基组有限**（缀加半径不能取很大）等数值因素；原文作者也明确 **PAW 不算是「全电子计算」**。所以「选对赝势变体 + 定好 `ENCUT`」才有意义（见 `errors.md` §1.4）。
- **一个直接相关的参数**：VASP 只把 PAW 球内**按 l 分解**的电荷密度写到 `LMAXMIX` 限制的阶数，所以做 **DFT+U**、或 **`ICHARG=11/12`** 这类读写电荷密度的计算时，要按元素设 `LMAXMIX`（s/p → 2，d → 4，f → 6）。

> 出处：知乎《PAW（Projected augmented wave）算法介绍》（`articles/20261001-PAW_Projected_augmented_wave_算法介绍.md`）＋ VASP Wiki 的 `ICHARG` 条目（关于 `LMAXMIX` 的说明）。

### 3.2 怎么挑 `POTCAR`：目录、后缀与精度权衡

**先认清赝势库里这五个目录 ↔ 泛函/方法的对应**：

| 目录 | 是什么 |
| --- | --- |
| `paw/` | **PAW-LDA** |
| `paw_gga/` | **PAW-GGA-PW91** |
| `paw_pbe/` | **PAW-GGA-PBE**（最常用） |
| `pot/` | **USPP-LDA** |
| `pot_GGA/` | **USPP-GGA** |

- 赝势按**产生顺序**是：模守恒（NC）→ 超软（USPP）→ **PAW**（现在的主流）。
- 同一元素在同一目录里往往还有**多个版本**，差别来自两方面：
  - **按 `ENMAX` 大小**：`Ga`（普通）、**`Ga_s`（soft，截断能更低）**、**`Ga_h`（hard，截断能更高）**；
  - **按半芯态处理**：**`Ga_sv`**（把 s 电子当半芯态）、**`Ga_pv`**（把 p 电子当半芯态）——
    半芯态纳入越多，价电子越多，**越准也越贵**。
- **USPP 与 PAW 怎么选**：
  - **USPP**：需要的截断能小、**算得快**；
  - **PAW**：截断能通常更大、纳入的电子更多、**慢但更精确**；
    **化合物（不同原子半径的元素混在一起）里 PAW 明显更可靠。**
  - 与 `errors.md` §1.4 的选变体规则配合使用——**看 `POTCAR` 第二行的价电子数**来判断某个版本是不是你要的。
- 💡 **两条实践原则**（比记住后缀更重要）：
  1. **算某个性质之前，针对该性质做一次赝势测试**——不同性质对赝势的敏感度不同；
  2. **比较不同赝势的结果时，看「能量差」，不要看绝对能量**——绝对能量本身依赖赝势的定义，不可比。

> 出处：《VASP 赝势简介》（`articles/20261001-VASP赝势简介.md`，转载自 52souji.net）。

> 📌 **按元素分区、按计算类型的官方选势建议**（第一行元素/碱土/d 区/p 区/f 区分别该用哪个后缀、GW 与杂化泛函的禁忌、版本与类氢势的坑）见 `references/potcar.md`。

> 📌 **所有 INCAR 参数的含义与取值**（全局/电子步/离子步分类速查）见 `references/incar.md`。

### 3.3 为什么通常要分三步算？KPOINTS 为什么要变？

初学者最常见的困惑之一（也是文章评论区的高频问题）：**为什么 `opt`/`scf`/`band` 三个文件夹里的
`KPOINTS` 不一样？**

- **`opt`（结构优化）**：要**固定/放开原子与晶格**去找到能量最低的结构——**电子步要自洽**，
  所以用**自动生成的网格**（均匀撒点）来积分布里渊区；
- **`scf`（静态自洽）**：结构定下来后**只调电子**，得到基态的**费米能级、波函数、电荷密度**
  （`WAVECAR`/`CHGCAR`）——同样用**自动网格**（网格可与 `opt` 一致或更密）；
- **`band`（非自洽）**：**电荷密度不再更新**（`ICHARG=11` 直接读上一步的 `CHGCAR`），
  只需要沿着**高对称路径**取点得到能带——所以 `KPOINTS` 换成**路径模式**（权重为 0 的 k 点）。

**一句话**：`opt`/`scf` 的 k 点是为了**积分（自洽）**，`band` 的 k 点是为了**沿路径画能带**——
**目的不同，所以文件不同**；把 `band` 的路径 k 点拿去自洽、或用自洽网格去画能带，都是错的。

**为什么不能省掉 `scf`（用优化目录里的文件直接算能带）？** ——因为**结构优化过程中写出的 `CHGCAR`/`WAVECAR`对应的是「最后一步迭代」的电荷密度与波函数，而不是「优化完成后」的体系**：优化后的结构可能已与最后一步略有差别，两者的电荷密度/波函数并不完全一致。**所以拿静态自洽（固定结构、重新自洽）产生的那一套文件去算能带，精度更好**；直接用优化目录的 `CHGCAR`/`WAVECAR` 属于「可以算但精度略差」的做法。

- ⚠️ 做非自洽步时，**除 `ICHARG`/`LORBIT` 这类开关外，`ENCUT`/`EDIFF` 等要与自洽步保持一致**，
  否则会出"`CHGCAR` 维数不同"一类问题（见 `errors.md` §8.24）。
- ⚠️ 另外，**`scf` 是静态单点，不是离子弛豫**：把 `NSW` 设为 `0`（有读者指出"`scf` 不该用 `IBRION=2`"——
  `NSW=0` 时离子本来就不会动，所以 `IBRION=2` 不会算出错误结果，但按惯例静态计算应把 `IBRION` 设为 `-1`、`NSW=0`，
  见 `references/incar.md` §三）。

## 五、三个"上手即用"的算例（思路与公式）

### 1. 吸附能（可类推掺杂能）

- 分别算三样：`E1` 吸附物分子、`E2` 干净表面、`E3` 吸附后的体系（**同一格子、同一套参数**）；
- **`E_ads = E3 − E2 − E1`**，**越小（越负）越容易发生**；
- 用来比较不同吸附构型（如 N₂ 横躺 vs 竖立），判断最可能的方式。
- **掺杂能**公式与之类似，只是把"吸附物"换成"掺杂原子"。

### 2. 迁移能垒（扩散势垒）

- **最简做法（等距插点）**：在稳定位置 A 到 B 的路径上**等距离插几个点**，
  逐点算能量，**最高点能量 − 稳定点 A 的能量 = 能垒**；
- **要准就用 NEB / CI-NEB**：VASP 内嵌，不必了解原理也能用；插点法适合先摸清路径与数量级。
- 电池材料里常问的"锂离子在正极材料中的迁移能垒"就是这个量。

### 3. 孪晶晶界与晶界能

- 计算上**能模拟的晶界主要是孪晶晶界**（晶界两侧晶粒关于界面**对称**）；
- 构建思路：先切出目标晶面（如 `111`，用 Materials Studio / VESTA）→ 把上半部分原子**翻转/镜像**拼上；
- **晶界能 =（含晶界的晶胞能量 − 初始晶胞能量）/ 2**（除以 2 是因为晶胞里有**两个**晶界）；
- 可以扫不同取向（`001`/`010`/`100`/`110`/`011`…）的能量，最低者最稳定、最可能出现在真实晶粒中。

## 八、最小可跑算例：单个 O 原子（官方例子）

> 第一次跑 VASP 就用这个：四个文件都很小，几分钟出结果，用来验证**环境配置与提交方式是否通了**
> （也就是一个 smoke test）。跑通了再上真实体系。
> 来源：一篇新手学习记录（`articles/20261001-VASP学习记录_二_VASP的第一次尝试_1.md`）。

### 8.1 `INCAR`

```
SYSTEM = O atom
ISMEAR = 0
SIGMA  = 0.01
ISPIN  = 2
```

- `SYSTEM` 只是标签，**与计算无关**。
- **展宽怎么取**：`ISMEAR=-5` 时 `SIGMA` 可以不管；**金属** `ISMEAR=1`（或 `0`）、**非金属** `ISMEAR=0`，
  一般 `SIGMA=0.10`（VASP 默认 `0.20`，不放心可用 `0.05`）；
  **原子 / 气体分子体系：`ISMEAR=0` + `SIGMA=0.01`**（照这个组合写就对了）。
- `ISPIN=2` = **考虑自旋极化**（`1` 是默认值、不考虑）；**单原子、O₂ 这类分子、含 Fe/Co/Ni 的体系**
  一般都要开。

### 8.2 `KPOINTS`

```
K-POINTS
0
Gamma
1 1 1
0 0 0
```

- 第 1 行随便写，**但不能没有**；
- 第 2 行 `0` = 自动生成 k 点；⚠️ **这个 `0` 常被误写成字母 `o`**（与 POSCAR 里 `O`/`0` 混淆是同一类错误）；
- 第 3 行**只认首字母、大小写均可**：`Gamma`/`G`/`g` = **Γ 中心网格**；`Monkhorst`/`M` 等 = 原始 MP 网格。
  两者的关系是**平移**：**MP 相当于把 Γ 中心网格在三个方向平移 `1/(2N)`**（等价说法：Γ 中心 = MP 平移 `0.5 0.5 0.5`）；
- 第 3 行**只认首字母**（`Gamma` / `g`）表示以 Γ 为中心撒点；
- 第 4 行三个方向的网格数，**原子/分子用 `1 1 1`**；
- 第 5 行是偏移（`0 0 0`）。

### 8.3 `POSCAR`

```
O atom in a box
1.0
7.5 0.0 0.0
0.0 8.0 0.0
0.0 0.0 8.9
O
1
Cartesian
0 0 0
```

- 第 1 行标签（随便写，不能没有）；第 2 行**缩放系数**；
- 3–5 行是格子矢量：**这里三个方向故意取不同长度（7.5 / 8.0 / 8.9），目的是降低体系对称性**；
- 第 6 行元素符号（**vasp4 没有这一行**，现在基本没人用 4.x）；第 7 行对应原子数；
- 第 8 行坐标系：**只认首字母**——`D`/`d` = 分数（Direct）；**`C`/`c`/`K`/`k` = 笛卡尔**（`K` 是德文 *kartesisch* 的首字母，在老教程与老脚本里很常见，别以为是笔误）；
- 第 9 行起是坐标；原子放哪都行（周期性决定近邻距离），但 **`CONTCAR` 里 VASP 输出的是分数坐标**。

### 8.4 `POTCAR`

- 选 **第一行是 `PAW_PBE O 08Apr2002`** 的那一版（示例）；选**变体**的完整规则看 `errors.md` §1.4
  （**看 POTCAR 第二行的价电子数**）。
- 多元素时按 **POSCAR 的元素顺序**拼接（见 `errors.md` §1.4）。

### 8.5 ⚠️ Windows 上的新手陷阱（都踩过）

- **输入文件不能带后缀**：`INCAR.txt` 不行；建议用 **Notepad++** 编辑——系统记事本可能写入 BOM / 改换行，
  导致 VASP 读不了。
- **元素符号 `O` 与数字 `0` 极易混淆**，务必看清楚。
- ⚠️ **老教程里的 `POSCAR` 往往是 VASP 4 格式（没有元素行）**：直接照抄到 VASP 5/6 会**整行错位**——VASP 5 会把「原子数行」当成「元素行」来读。用老例子时必须**自己在原子数行前补一行元素符号**。
- **省略元素行也能算**：若目录里已有匹配的 `POTCAR`，VASP 会**按 `POTCAR` 里元素的顺序**推断，并在输出的 `CONTCAR` 里把那行补回来（两个独立来源都记录了这一点）。
- **元素行的第一个符号要顶格**，前面有空格可能报错。
- 如果文件夹里已经有与结构一致的 `POTCAR`，**POSCAR 里那行元素删掉也能算**
  （VASP 会从 `POTCAR` 读元素），输出的 `CONTCAR` 会自动补上。
- **提交方式因集群而异**：一般服务器会提供提交模板，没有就找管理员（社区回答）。

### 8.6 跑完看什么

文件夹里会多出一堆输出文件（`OUTCAR`、`OSZICAR`、`CONTCAR`、`CHGCAR`…）。
先 `grep "reached required accuracy" OUTCAR` 或看 `OSZICAR` 是否收敛；有报错就按 `errors.md` 的诊断流程走。

## 九、VASP 输出文件一览（跑完之后都有什么）

> 四个输入文件讲完了，这里是"跑完会多出什么、各看什么"。
> 需要**排错**时优先看 `OUTCAR`（见 `errors.md` 的诊断流程）；要**提取数据画图**看
> `workflows.md` §二十（OUTCAR 数据挖掘）与各性质对应的小节。

| 文件 | 是什么 | 关键点 |
| --- | --- | --- |
| **`OUTCAR`** | 最完整的日志 | 能量、受力、应力、收敛、迭代耗时、警告全在里面；**诊断与取数的首选** |
| **`OSZICAR`** | 每步的**简要汇总** | 看收敛最方便（`N`=电子步数、`E`=当前能量、`dE`=与上一步之差、`d eps`=能带能量变化、`ncg`=哈密顿量求值次数、`rms`=波函数残差范数、`rms(c)`=电荷密度残差（**前几步电荷密度不参与迭代**）、**`mag`=磁矩**）；行首的 `DAV` 是**电子迭代算法**（由 `ALGO` 决定，`DAV` 是默认）；**离子步那一行的 `F` = 体系总能，与 `OUTCAR` 里 `free energy TOTEN` 相等**，**`E0` 对应 `OUTCAR` 的 `energy(sigma->0)`** |
| **`CONTCAR`** | **优化/演化后的新结构** | 格式同 `POSCAR`，**可直接当下一轮的 `POSCAR`**；与 POSCAR 有三点差别：① 坐标写得**更精确**；② 用 **`Direct`（分数坐标）**；③ **多出一段"原子移动（位移/速度）"信息**——每个原子一行。<br>💡 **MD 时这些数不为 0**：把 `CONTCAR` 拷成 `POSCAR` 就是**续算轨迹**，VASP 会读这些速度（正好补上 §八 里「不给初速度就随机生成」的另一半）。 |
| **`CHGCAR`** | 电荷密度**格点文件** | 结构：**前 `8 + 原子数` 行 = POSCAR 内容** → **一个空行** → **一行 `NGXF NGYF NGZF`** → `NGXF×NGYF×NGZF` 个密度值；**每步迭代都会更新**，文件极大（几十万行）；自旋极化时还多一段自旋密度（详见 `workflows.md` §十五）。 |
| **`IBZKPT`** | **不可约布里渊区的 k 点** | 用自动模式生成 k 点时，VASP 把简约化后的 k 点矩阵写在这里，**可以直接把其中的数据拷进 `KPOINTS`** 当显式 k 点列表用。 |
| **`DOSCAR`** / **`PROCAR`** / **`EIGENVAL`** | 态密度 / 投影 / 本征值 | 画 DOS、能带、fatband 的原料（见 `workflows.md` §三、§四）。 |
| `XDATCAR` / `CHG` / `WAVECAR` / `LOCPOT` / `PCDAT` | 轨迹、旧电荷、波函数、静电势… | 按需使用；`WAVECAR`/`CHGCAR` 也用于续算。 |
| `REPORT` / `vasprun.xml` / `vaspout.h5` | 结构化记录（VASP 6 起 `vaspout.h5`） | 后处理脚本会读（如 `scripts/parse/`）。 |

- **来源**：本节主要来自一篇新手学习记录
  （`articles/20261001-VASP学习记录_七_VASP的其它输出文件.md`）——作者本人也说明**只对 `CONTCAR`/`CHGCAR`/
  `OSZICAR` 有实际使用经验**，`IBZKPT` 之后是按资料整理的，本库已把这些条目与库内其它文档互相挂钩。



### 9.1 `OUTCAR` 的九个部分（导航）

`OUTCAR` 用**长横虚线**把内容分成若干块；想找东西就先认块。按顺序大致是：

| # | 部分 | 里面有什么 | 干什么用 |
| --- | --- | --- | --- |
| 1 | **基础信息** | VASP 版本、在多少个核上运行 | 排查"环境/编译/并行"类问题 |
| 2 | **Warning 与 POTCAR** | 开头那段 `NCORE` 建议的 warning + POTCAR 回显 | 💡 **只要计算正常结束，那段 warning 可以直接忽略**（无论成功失败都会出现，与 `errors.md` §8.19 同一条） |
| 3 | **基础分析** | POSCAR 回显 + **对称性分析**（静态/动力学/磁）+ 点群操作 + k 点 | 判断"对称性对不对"（例：把三个边长设成不同值时是简单正交、`D_2h`、8 个操作；**三边相等就是 48 个操作、立方**——这就是 §8.3 里"故意取不同长度降低对称性"的效果） |
| 4 | **INCAR 回显** | 你写的 + **VASP 补全的默认值** | 💡 **想知道某个参数"实际用了多少"，直接在这里看** |
| 5 | **正式计算前的总结** | `energy-cutoff`、`volume of cell`、正/倒格矢、**两套 k 点**、分数/笛卡尔坐标、平面波数、`maximum index in each direction`（`IXMAX/IYMAX/IZMAX`）、**内存统计**（base / nonl-proj / fftplans / grid / wavefun）、`Broyden mixing: ... NGX/NGY/NGZ`、`number of electron`、`magnetization` | 估算内存、核对 k 点与 FFT 网格（§8.14 的 FFT 网格不一致就是比这里的 `NGX/NGY/NGZ`） |
| 6 | **正式计算记录** | 每一个电子步一块（能量、`rms`、`ncg`…） | 看收敛过程（更方便的是 `OSZICAR`） |
| 7 | **费米能级与能带信息** | `E-fermi`、`XC(G=0)`、`alpha+bet`、**`band No. / band energies / occupation` 表**；`ISPIN=2` 时分成 **spin component 1/2** | 取能带、带隙、HOMO/LUMO（见 `workflows.md` §二十 的 bash 路线） |
| 8 | **力与能量** | `aborting loop because EDIFF is reached`、各环节 CPU 时间、**`FORCE on cell = -STRESS`**（逐项：Ewald/Hartree/E(xc)/Local/augment/Kinetic…→ Total→ `in kB` → **`external pressure`**、`Pullay stress`）、`FORCES acting on ions`、**最后的总能量** | 取应力/压强、看能量与受力；**"我们要的能量"通常就是这最后那个数** |
| 9 | **结尾** | 实际内存与时间统计 | 一般不用看 |

（`NWRITE` 可以控制 `OUTCAR` 写多详细。）

### 9.2 常用"一行命令"

| 想要什么 | 命令 |
| --- | --- |
| 最后的能量 | `grep without OUTCAR \| tail -1`（`tail -1` 取**最后一个离子步**）；⚠️ 这一行里 `energy without entropy` 与 `energy(sigma->0)` **在同一行**——**要取的是 `energy(sigma->0)` 那个值**，它才与 `OSZICAR` 的 **`E0`** 对应（**一般就用它**）；`OSZICAR` 离子步那行的 **`F`** 则等于 `free energy TOTEN` |
| 费米能级 | `grep E-fermi OUTCAR` |
| 不可约 k 点数 | `grep irreducible OUTCAR`（等价 `grep irre OUTCAR`） |
| 体系体积 | `grep volume OUTCAR` |
| 是否收敛 | `grep "reached required accuracy" OUTCAR` |
| FFT 网格（差分电荷要一致） | `grep NGX OUTCAR` |
| 有哪些元素 | `grep TIT OUTCAR` |
| 价电子数 | `grep ZVAL OUTCAR` |
| 赝势建议的截断能 | `grep ENMAX OUTCAR` |
| **每个离子步耗时** | `grep LOOP+ OUTCAR` |
| **每个电子步 + 离子步耗时** | `grep LOOP OUTCAR` |

### 9.3 结构优化之后，该记录 / 检查哪些指标

> 一篇实操长文给的"优化后信息清单"——**计算前检查初始文件、计算中检查弛豫过程、计算后检查结构与指标**。
> 下面这些量都能从 `OUTCAR`/`OSZICAR`/`CONTCAR` 里取（命令见 §9.2）。

| 指标 | 取自 | 说明 |
| --- | --- | --- |
| **`E0`** | `OUTCAR` 最后一个 `energy(sigma->0)` | 优化后的体系能量（**一般就用它**，见 §9.2） |
| **`EENTRO`** | `OUTCAR` 最后的 `EENTRO` | 展宽带来的"熵"项；金属体系用它反推 `SIGMA`（目标 `EENTRO/atom` ≈ 1–2 meV） |
| **是否收敛** | `OUTCAR` 是否出现 `reached required accuracy - stopping structural energy minimization` | 出现即弛豫收敛 |
| **`external pressure`** | `OUTCAR` 最后一个 | 不加压计算时绝对值通常 < 1 |
| **`Pullay stress`** | `OUTCAR` 最后一个 | 不加压计算应为 0 |
| **`Edisp`** | `OUTCAR` 最后一个 | vdW 校正能量；**没开 vdW 会输出 `--`** |
| **`Elapsed time`** | `OUTCAR` | 本次计算耗时 |
| **总磁矩 `mag`** | `OSZICAR` 最后一个 | 磁性体系必记 |
| **三种点群** | `OUTCAR` 的 static / dynamic / magnetic configuration | 分别对应结构、动力学、磁态对称性 |
| ⭐ **`(POSCAR − CONTCAR)/POSCAR`** | 自己算（三个格矢分量 + 各晶格常数） | **Total > 1% 就考虑用 `CONTCAR` 再优化一轮** |
| **原子磁矩** | `OUTCAR` 最后一个离子步（`ISPIN=2` + `LORBIT=11`，见 §9.2） | 磁性体系必记；**若 `ISPIN=1`，或每个原子的磁矩绝对值都 < 0.01，按无磁处理** |

**两条"能不能凑合用"的判断**（原文讨论）：

- **弛豫给出的 `DOSCAR`**：手册明确说弛豫时写的是**平均 DOS**（"For relaxations, the DOSCAR is usually useless"）。
  若弛豫只跑了很少步（≤20 步）、结构变化很小，可以拿它**粗略判断金属/半导体与带隙**，但正经 DOS 要另行自洽计算。
- **弛豫给出的能量**：晶格变化较小时（晶格常数、夹角相差 5% 以内）可用于**快速判断**（如吸附能、FM/AFM 能量差）；
  **20 步内快速收敛且晶格变化 < 1% 时，与后续静态计算几乎一致**（原文示例：吸附自由能差 < 1 meV）。
  但**要更准，仍应加密 k 点做一次自洽**。

- 💡 **磁性体系的一条硬性要求**：记录好弛豫后的磁矩信息，并且**后续每一步计算（单点能、能带、声子谱）都要检查自洽结束后的磁矩**
  ——确保体系收敛到了弛豫给出的那个磁态。
